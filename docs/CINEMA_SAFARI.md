# Продолжение просмотра в Safari · 0.2.9 (build 11)

В [версии 0.2.10](CINEMA_TAVILY.md) добавлен основной провайдер Tavily
с хранением ключа в macOS Keychain; Brave сохранён как необязательный.

Проверено 4 ноября 2026 года. Существующая медиатека, TMDB, история, списки,
оценки и источники сохранены. Новая миграция добавляет журнал этапов и последнее
подтверждённое состояние плеера, включая озвучку. SQLite использует WAL и
фиксирует обновления прогресса транзакциями.

## Что реально работает

«Продолжить» проверяет сохранённую серию и источник, подключённые адаптеры,
а при отсутствии точной серии — официальный Brave Search API. Поиск использует
русское, оригинальное и альтернативное название, год, сезон, серию и язык.
Первый запрос может ограничиваться последним источником, остальные ищут по
общему индексу, без фиксированного списка сайтов. Максимум три поисковых запроса
за один поиск; автоматических повторов после ошибок и лимитов нет.

**Brave требует личный ключ.** Он вводится в «Настройки медиатеки → Поиск и Safari»
и хранится в закрытом `data/integrations/brave-search.json` (0600), вне Git,
экспорта медиатеки, HUD-снимков и LLM. Реальные платные запросы с пользовательским
ключом в проверках не выполнялись: ключ не предоставлен. Протокол API, заголовок
авторизации, отсутствие утечки при редиректе, ограничения и весь путь до
сохранённой серии проверены с тестовым транспортом. Документация:
[Brave Web Search](https://api-dashboard.search.brave.com/app/documentation/web-search).

Результат поисковика — только кандидат. Проверяются публичный HTTPS URL,
robots.txt, ограничения/перенаправления и структурированные метаданные Movie,
TVSeries или TVEpisode. Для серии нужны точная идентичность сериала, год либо
совпавший IMDb ID, сезон и номер серии. Сниппет не доказывает наличие видео.
Запреты, CAPTCHA, Cloudflare, авторизация и DRM не обходятся. Отсутствие
robots.txt с HTTP 404 допускается; защитный HTTP 403 останавливает проверку
([RFC 9309](https://www.rfc-editor.org/rfc/rfc9309.html)).

Ранжирование учитывает точность серии, сохранённый/закреплённый и действительно
работавший источник, озвучку, заявленный язык, бесплатность, опубликованные
ISO-регионы и возможность HTML5-управления. Региональный параметр поисковика
не доказывает право просмотра. Неизвестная региональная доступность остаётся
неизвестной. Новый сайт требует первого явного выбора/подтверждения; затем
выбранная страница сохраняется и переиспользуется. Изменение запомненной
озвучки требует подтверждения. Источник с работающей сохранённой точной серией
имеет приоритет перед поиском нового.

В Safari выбирается один доступный HTML5-плеер, включая iframe того же origin.
Открытие вкладки, готовность метаданных, восстановление времени и реальное
движение позиции различаются. По умолчанию позиция восстанавливается с отступом
3 секунды; значение настраивается от 0 до 30. При несовпадающей длительности,
недоступном плеере или запрете autoplay показывается сохранённый таймкод.
Автоматическое воспроизведение можно отключить отдельно от открытия страницы.

Периодические события, пауза, перемотка и доступный `pagehide` сохраняют прогресс.
Опрос остаётся резервом. Ошибки, пустая длительность, неподтверждённый запуск и
нулевые показания не затирают последнее корректное состояние. При закрытии
браузера/приложения сохраняется уже зафиксированный прогресс; недоставленное
последнее событие может оставить погрешность до интервала опроса. После
перезапуска воспроизведение само не запускается — требуется «Продолжить».

Настоящее окончание видео предлагает следующую серию. По настройке можно
автоматически открыть следующую совместимую точную серию. Если серии ещё нет
в локальной библиотеке, загружаются опубликованные номера из TMDB; адреса
видео не сочиняются. Закрытие вкладки само по себе не запускает следующую серию.

## На каких сайтах

- Реально проверен Safari на собственном HTTP-стенде с созданным видео без звука.
  Это доказывает работу интеграции, а не совместимость любого сайта.
- KION: адаптер читает опубликованные ссылки серий на подтверждённой странице
  сериала. Для точной серии дополнительно проверяется ответ TVEpisode.
- Internet Archive и существующие адаптеры продолжают работать. Через Brave
  можно находить другие сайты с проверяемыми публичными метаданными. Их плееры
  проверяются уже в Safari; само обнаружение нового домена не означает его
  безопасность, легальность или пригодность для автоматического управления.
- Filmix/Kinogo сохраняют ограничения, описанные в [отчёте 0.2.8](CINEMA_AUTOPLAY.md).
  Поисковый API не используется как способ обхода запрещённых маршрутов.

## Где восстановлено точное время

На реальном Safari-стенде подтверждены:

- Открытие конкретного URL серии и обнаружение HTML5-видео.
- Восстановление с 9 секунд примерно на 6 секунд, затем подтверждённый запуск.
- Пауза, перемотка, сохранение, закрытие именно тестовой вкладки.
- Перезапуск сервиса и SQLite, повторное открытие и восстановление последней
  сохранённой позиции с поправкой назад.
- Достижение реального конца видео, предложение второй серии и автоматический
  переход к ней при включённой настройке.
- Сохранённый подтверждённый статус плеера и все семь этапов диагностики.

Команда: `.venv/bin/python -m scripts.check_cinema_safari --live`.
Она использует подписанного помощника установленного приложения, временные
SQLite/видеофайл и только свои URL. Микрофон, настройки безопасности Safari и
посторонние вкладки не изменяются. Проверка запускается явно, не при старте.

Дополнительно прошли 2274 Python-теста, 112 frontend-тестов, Ruff,
форматирование, TypeScript/Vite и реальный Chromium-стенд с видео, проверками
старой кинотеки, мобильной ширины, UNKNOWN и встроенного плеера.

## Где возможен только переход на страницу

Для «Бара „Один звонок“» (TMDB tv:250727, 2025) реально получены ссылки,
опубликованные самим KION. Найдена и проверена
[сезон 1, серия 2](https://kion.ru/serial/bar-odin-zvonok/sezon-1/seriya-2):
HTTP 200, метаданные TVEpisode, правильная привязка к сериалу и номер серии.
Страница открыта в настоящем Safari. Доступный HTML5-плеер не найден;
управление воспроизведением и точное время на этой странице **не подтверждены**.
Вход, подписка и защищённый плеер остаются на стороне сервиса.

Опубликованная ссылка первой серии `/video/.../sezon-1/seriya-1` перенаправляет
на сезон; уникальная страница первой серии не подтверждена. Адаптер не
придумывает альтернативный URL и не объявляет общую страницу запущенной серией.

При cross-origin iframe, DRM, запрете JavaScript/автопроигрывания либо отсутствии
подходящего video Чушпан показывает конкретное ограничение. Сохранённые
таймкоды и ручная коррекция доступны в карточке. Подписка, регион и реклама
не проверяются обходом авторизации или доступом к cookies.

## Какие разрешения Safari включить

Выбран существующий поддерживаемый механизм **Apple Events**, поскольку на этом
Mac установлены Command Line Tools без `safari-web-extension-converter`/полного
Xcode. Safari Web Extension Чушпана не собрано и не установлено; интерфейс
это сообщает. Не выдаём подготовленный исходник расширения за работающую
интеграцию. Архитектура и ограничения Safari Web Extension описаны
[Apple](https://developer.apple.com/documentation/safariservices/messaging-between-the-app-and-javascript-in-a-safari-web-extension).

1. Разрешить Чушпану/его подписанному помощнику **Автоматизация → Safari**.
   Кнопка «Запросить доступ к Safari» вызывает только этот явный запрос.
2. В Safari включить функции для веб-разработчиков, затем в настройках
   разработчика **Allow JavaScript from Apple Events**. Названия и расположение
   пунктов могут отличаться между версиями Safari
   ([документация Apple](https://developer.apple.com/documentation/safari-developer-tools/developer-settings)).
3. Если сайт блокирует play, разрешить autoplay конкретному сайту либо нажать
   ▶ вручную. Чушпан не меняет эти настройки автоматически.

Кнопка «Проверить интеграцию с Safari» не читает содержимое пользовательской
страницы: проверяются разрешение и постоянное выражение JavaScript. Права
Terminal/другой копии не считаются разрешением установленного приложения.
Диагностика хранит до 300 локальных событий, интерфейс показывает последние 40:
SEARCH → VERIFY → OPEN_SAFARI → DETECT_PLAYER → RESTORE_POSITION → PLAY → SAVE_PROGRESS.
