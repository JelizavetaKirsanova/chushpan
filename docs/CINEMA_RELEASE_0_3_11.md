# Поиск и воспроизведение: 0.3.11 (24) и 0.3.12 (25)

## Причина общего отказа

Проблема воспроизведена в установленной 0.3.10 (23), соответствовавшей актуальному
коммиту `0b80563`. Устаревшая сборка и конфликт backend-портов не были причиной.

Цепочка отказа состояла из нескольких связанных условий:

- Часть настроенных источников возвращала главную страницу или форму поиска.
  Они попадали в общий список вместе с точными страницами и ошибками API.
- Выбранный поисковый API был единственной интернет-стратегией: бесплатного
  браузерного резерва при отсутствии ключа, лимите или неподходящих результатах не было.
  Поздняя ошибка/таймаут могла также уничтожить уже законченные результаты проверки.
- Автовыбор требовал доказательства полного видео до открытия динамического плеера,
  а первый запуск проверенного открытого источника зависел от его предыдущего успеха.
  В проверенной конфигурации такого прямого источника вообще не было.
- Анонимные метаданные страницы, тип видео, стоимость, регион, управление и реальный
  запуск не были достаточно разделены в интерфейсе. Диагностика подставляла общую
  фразу классификатора вместо конкретного HTTP/API-сбоя.
- Живой Playwright обнаружил отдельный дефект: официальный файл Archive после
  перенаправления на CDN отвергался валидатором, хотя произведение, имя файла и
  полная длительность совпадали.

TMDB остаётся каталогом. Ни одно исправление не превращает его карточку, главную
страницу киносайта, трейлер или недоступную по правам запись в полный видеопоток.

## Изменения цепочки

`SourceManager.search/_search` разделяет наблюдения по странице, произведению,
серии, видео, региону, плееру, управлению и воспроизведению. Стоимость `UNKNOWN`
не означает недоступность. У точной страницы появился отдельный путь проверки
плеера, не требующий заранее объявлять видео полным.

`InternetSearch.search` сохраняет результаты законченных проверок и конкретные
отклонённые URL; проверяет страницы параллельно с ограничениями времени.
`SearchProviders.search` после выбранного API использует бесплатный поиск в
собственном окне Safari, включая регион EE (`kl=ee-et`). Другой платный API
автоматически не вызывается. Окна и вкладки пользовательницы не переиспользуются.
CAPTCHA, отсутствие Apple Events/JavaScript-разрешений и изменения сайта останавливают
этот путь с конкретной причиной.

`PageVerifier.verify` различает совпадение по структурированным данным и вероятное
совпадение видимого заголовка/года. Второе доступно только через явное открытие
браузера; оно не допускается в автоматический Play или подтверждение прогресса.
Общая страница сериала не выдаётся за точный эпизод.

`Cinema._resume/source_result/try_resolution` запускают проверенный открытый источник
при первом просмотре без ключа и ранее сохранённой ссылки. Если Safari не подтверждает
этот просмотр, допускается одна попытка того же проверенного файла во встроенном
плеере. Явно выбранный пользователем движок сохраняет своё значение. Неподдерживаемое
управление доступной страницей не записывается как недоступность самого источника.

`archive_open.verified_alias` принимает официальный CDN только с точным идентификатором
произведения и тем же файлом; чужой домен, другой файл, HTTP, подписанный query и
несовпадающая длительность отвергаются. Добавлен полнометражный фильм **Sita Sings the
Blues**, автор Nina Paley, CC0, связанный MP4 от полного оригинального OGV, 4891,24 с.
Это ограниченный проверенный каталог, а не обещание доступности любых загрузок Archive.

Реальный поиск Safari через установленный подписанный помощник также проверен: получены
конкретные URL результатов без API-ключа. При этом найденные ссылки ещё проходят
независимую проверку — результаты поисковика не объявляются полным видео. Обнаружена
и исправлена несовместимость JSON Unicode-escape с AppleScript: встроенный JavaScript
передаётся с исходными Unicode-символами.

## Playwright в настройках

`browser_diagnostics.py` и `cinema_browser_diagnostics.ts` добавляют отдельные действия
«Исследовать страницу», «Проверить Play и currentTime», отмену и копирование отчёта.
Chromium запускается только по запросу диагностики. Обычный просмотр сохраняет
Safari/WKWebView/AVKit. Изолированный контекст не получает профили, cookies или
авторизацию браузера пользовательницы.

Проверяются HTTP, видимый заголовок/год, структурированные данные, iframe, открытые
shadow roots, video/source, подписанные кнопки, нативные списки сезонов/серий,
ошибки JavaScript и сети, DRM, движение currentTime и доступный fullscreen.
Элементы обнаруживаются заново по роли, подписи и структуре; профиль сайта добавляет
только доверенные варианты подписей. Старые DOM-дескрипторы не кешируются.

Отчёт включает независимые результаты, длительности этапов и хеш структуры страницы.
Изменение структуры приводит к новому обнаружению, а не к применению старого селектора.
Проверки ограничены по времени и отменяются вместе с собственным браузером.
Движение времени подтверждается только при неизменных URL и длительности активного
видео. Для автоматического Play требуется отдельное доказательство полного видео.

JSON и снимки страниц сохраняются в личном каталоге
`data/cinema-browser-diagnostics/`, вне Git. Заголовки запросов, cookies, HAR и тела
ответов не сохраняются; URL в отчётах лишены query/fragment/credentials. Доступ к
снимкам из интерфейса ограничен тем же origin. Успешная проверка может запомнить
точную привязку источника, но не пишет просмотр и не меняет сохранённый таймкод.

## Реальные проверки 7 ноября 2026

Все следующие результаты получены реальными сетевыми запросами/браузерами на этом
Mac, с выбранным регионом EE. Географическое положение внешнего IP отдельно не
проверялось. HTTP 403 и отсутствие плеера сами по себе не называются блокировкой EE.

- **Sita Sings the Blues (2008), Playwright:**
  [полный MP4](https://archive.org/download/Sita_Sings_the_Blues/Sita_Sings_the_Blues.mp4),
  конечный официальный CDN `dn720802.ca.archive.org`. 4891,214 с,
  currentTime **0,063 → 1,865 с**, полное видео и движение времени подтверждены.
- **Sita Sings the Blues, production HUD в WKWebView:**
  currentTime **0,220 → 1,422 с**; пауза, seek на +10 с, fullscreen,
  сохранение 11,422 с, продолжение с 8,641 с и переключение двух профилей Archive
  подтверждены. Это отдельное временное окно на текущем коде, не доказательство
  запуска именно установленного пакета.
- **Caminandes S01E01, Playwright:**
  [полная серия](https://archive.org/download/Caminandes1LlamaDrama/01_llama_drama_1080p.mp4),
  currentTime **0,306 → 2,114 с**, полная серия и запуск подтверждены.
- **Caminandes S01E02:** один живой прогон получил HTTP 500 на CDN; сохранён снимок
  ответа сервера. Этот прогон не объявляется успешным.
- **KION:** найдена и открыта [страница «Интерстеллар»](https://kion.ru/film/interstellar).
  Доступная страница не предоставила единственный подтверждённый полный HTML5-плеер;
  воспроизведение не подтверждено. Вход, подписка и DRM не обходились.
- **Filmix:** поиск через видимую форму действительно нашёл
  [страницу «Последнее королевство»](https://filmix.gg/seria/drama/102209-v-novi-2x-poslednee-korolevstvo-2015.html).
  На проверенной странице не обнаружено доступного video/iframe полного эпизода.
  Название/год — вероятное совпадение; нужный сезон/эпизод и Play не подтверждены.
  Запрет `/search` в robots относится к фоновому HTTP, не подменяет результат
  отдельно разрешённого пользовательского браузерного сценария.
- **Kinogo:** браузер нашёл
  [точную страницу названия](https://kinogo.is/4748-poslednee-korolevstvo.html),
  хотя прежняя анонимная HTTP-проверка получала 403. Обнаружены кнопки плееров
  и iframe `https://api.nextembed.ws/embed/movie/610`; доступного video и
  подтверждения нужной серии не получено. Трейлер отдельно не запускался.
- **HDRezka:** открылась главная `https://hdrezka.sh/`, точная страница в этом
  браузерном сценарии не найдена. **Kinomania:** главная доступна, точная страница
  и полный плеер не найдены. **Kinetoon:** перенаправление на `https://kinetoon.com/ru`,
  нужная страница/плеер не подтверждены. Эти результаты не доказывают отсутствие фильма.

Инструмент повторного испытания: `python -m scripts.check_cinema_playwright --live ...`.
Сырые диагностические экспорты и снимки этих испытаний оставлены в `/private/tmp`,
не добавлены в репозиторий. Лицензия полного фильма подтверждается
[автором](https://blog.ninapaley.com/2013/01/18/ahimsa-sita-sings-the-blues-now-cc-0-public-domain/)
и [метаданными Archive](https://archive.org/metadata/Sita_Sings_the_Blues).

## Проверки кода и установка

0.3.11 (24), коммит `fb42d3a`, проверена после штатной установки в
`/Applications/Чушпан.app`. Проверки подписи arm64 и 18 импортов прошли. Из постера
через «Найти и смотреть» запустились фильм и первая серия, без привязанных ссылок
или платного API. Временная медиатека сохранила реальные позиции:

- **«Сита поёт блюз»**, 4891,189 с, позиция **10,220 → 16,241 с**.
- **Caminandes S01E01**, 90,0 с, позиция **0,184 → 3,236 с**.
- Кнопка **«Следующая серия»** открыла **S01E02**, 146,042 с,
  позиция **4,517 → 10,534 с**. Таймкод S01E01 сохранился отдельно.

Проверка Playwright в 0.3.11 выявила особенность PyInstaller. Драйвер искал Chromium
внутри подписанного `.app`. В 0.3.12 диагностика использует стандартный кеш
`~/Library/Caches/ms-playwright`. При отсутствии нужной версии Chromium диагностика
показывает команду для разовой установки в Терминале:

```bash
/Applications/Чушпан.app/Contents/MacOS/Chushpan --install-cinema-browser
```

Полный прогон обнаружил восемь сбоев старых тестов освещения. Все восемь независимо
воспроизведены на исходном `0b80563` в отдельном чистом снимке, без изменений медиатеки.
Ещё один тест Unix-сокета не прошёл внутри sandbox и прошёл при разрешённом повторе.
Работа с реальным BLE, микрофоном и физическими устройствами не выполнялась.
