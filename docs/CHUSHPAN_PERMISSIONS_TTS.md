# Разрешения ночного сценария и русское произношение

Проверка 31 октября 2026. Существующие изменения проекта сохранены.

## Разрешения и компоненты

- Голосовая команда требует Микрофон для приложения запуска Чушпана.
- Safari AX (окно, полноэкранный режим) требует Универсальный доступ для приложения запуска.
- Управление вкладкой и видео требует Автоматизация → Safari для приложения запуска,
  а также Safari → Разработка → Разрешить JavaScript из событий Apple
  (в новых версиях: Настройки → Разработчик → Автоматизация).
- BetterDisplay должен быть установлен; встроенный и настроенный внешний дисплеи
  должны однозначно определяться, а их яркость — читаться. Код аппаратной яркости
  и системной громкости не требует отдельного TCC-разрешения. Возможность записи
  зависит от дисплея/аудиовыхода и проверяется после каждого действия.
- Youtube sleep имеет собственные разрешения Команд: выполнение скриптов,
  Автоматизация для приложений, к которым обращаются её действия; Универсальный
  доступ нужен, если используется управление интерфейсом. Права другого приложения
  публичный TCC API не подтверждает. Поэтому нужна ручная проверка и существующий
  флаг night.shortcut_permissions_reviewed. Команда не изменялась.
- YouTube Sleep Timer отдельно не используется: окончание видео отслеживает
  существующая Youtube sleep. Запись экрана ночному сценарию не нужна.

Настройки TCC: Системные настройки → Конфиденциальность и безопасность →
Микрофон / Универсальный доступ / Автоматизация. Включать нужно приложение,
указанное macOS: Terminal, Codex либо Чушпан.app. Затем перезапустить его.
Команды → Настройки → Дополнения → Разрешить выполнение скриптов.

Проверка публичными API вне песочницы: Accessibility — granted; Automation
Safari — not_determined; Microphone — not_determined; Safari JavaScript —
not_checked; Screen Recording — not_granted (для ночного сценария не нужен).
По цепочке запуска найден Python.app, но это лишь подсказка, а не авторитетная
идентификация TCC. Эти статусы относятся к диагностическому процессу Codex;
для обычного запуска Чушпана их нужно повторить. В песочнице статусы отличались.
BetterDisplay установлен. Права самой Youtube sleep автоматически не установлены.

Команда «Чушпан, проверь разрешения» выполняет только чтение. Предварительная
проверка выполняется и перед ночным сценарием; неизвестные и недоступные условия
блокируют видео, запись яркости/громкости и Shortcut. Сбои чтения компонентов
теперь возвращают понятный отказ без текста внутренних исключений.

## TTS

Реальный вход Silero: backend/audio/tts.py, SileroSpeaker._synth → apply_tts.
Нормализованная копия создаётся speech_text через backend/audio/russian.py.
Ранее очистка оформления и подстановка единиц не обеспечивали произношение
чисел и латинских названий. Поведение конкретного аудио зависит от модели;
физическое прослушивание в этой проверке не выполнялось.

Нормализатор поддерживает целые, отрицательные и дробные числа, проценты,
время, даты, версии и единицы; согласует известные контексты по роду.
Словарь расширяется через tts.pronunciations в конфигурации. Неизвестная латиница
читается по буквам; DEBUG содержит только количество токенов. Код, ссылки,
секреты и пути заменяются в голосовой копии на «фрагмент в тексте».
Защита литералов выполняется до обработки числовых групп.

Текст интерфейса остаётся исходным. Для сохранения потокового воспроизведения
сначала собираются завершённые предложения с защитой литералов, затем идёт
нормализация перед синтезом. Это не нормализация отдельных LLM-токенов:
версия 3.8 и числа не распадаются между поступающими токенами. Полная буферизация
ответа до разбиения добавила бы задержку; она не вводилась.

git diff --check прошёл. Тесты покрывают отказ при отсутствии разрешений,
ошибки компонентов без побочных действий, числа, даты, версии, словарь,
неизменность отображаемого ответа и потоковую подачу с разным размером токенов.

1. Запустить «проверь разрешения» из обычного приложения запуска Чушпана.
2. Включить только перечисленные отсутствующие права и повторить диагностику.
3. Просмотреть действия Youtube sleep и её собственные разрешения; после
   проверки отметить night.shortcut_permissions_reviewed: true вручную.
4. Попросить произнести «31 видео, 25%, Python 3.12, Gemini 3.8 Flash,
   MacBook Pro, 12:31, 31.10.2026» и сравнить голос с исходным текстом интерфейса.
5. Ночной сценарий проверять отдельно, осознанно подтвердив его свежим кодом:
   он действительно изменяет яркость/громкость и может усыпить Mac.
