# Поиск кино и временные вкладки в Чушпане 0.3.13 (26)

В журнале 0.3.12 поиск «Последнего королевства», S01E01, вернул 21 строку.
В одном списке были страницы OK.ru, промо, ошибки API, результаты без метаданных
и ответы отдельных сайтов. Служебное окно Safari определялось через front window,
а закрытие зависело от текущей вкладки и исходного хоста. Кнопка отмены переставала
учитывать результат, но не отменяла сам запрос. Неподтверждённая сохранённая ссылка
могла унаследовать оценку точного совпадения.

- `BrowserSearch.discover` создаёт сессию с уникальной меткой. Два поисковых
  запроса используют одну вкладку в существующем окне Safari. Если окон нет,
  Чушпан создаёт своё и закрывает его, пока в нём одна отмеченная вкладка.
  В остальных случаях закрывается только вкладка с меткой операции. Очистка вызывается после
  результата, ошибки, тайм-аута, отмены и при выходе. Вкладки, оставшиеся от старой
  версии без подтверждаемой метки владельца, не считаются служебными.
- `SourceManager.search` использует sitemap как один из каналов. Дополнительно
  работают обычный интернет-поиск и видимые формы включённых сайтов в изолированном
  Playwright. Фоновый HTTP соблюдает robots.txt. Браузерная проверка прекращается
  при 403, запросе входа, CAPTCHA или региональном ограничении.
- `InternetSearch` сначала проверяет страницы поставщиков и распределяет
  проверку между разными доменами. Каталоги метаданных не считаются источниками.
  При разрешённом перенаправлении внутри сайта проверяется конечная страница.
- `PageVerifier.inspect` отдельно оценивает название, год, тип, координаты серии,
  признаки плеера и привязку к полному видео. Заголовок, описание, адрес и
  структурированные данные дают отдельные сигналы. Противоречащий номер отклоняется.
  Вероятная страница открывается по явному действию и не записывается как успешный
  просмотр. Проверка видео по-прежнему требует привязки к полному файлу и движения
  времени в плеере.
- Список убирает дубли адресов и показывает доступные варианты отдельно от
  вероятных совпадений. HTTP-ошибки, промо и причины отказа находятся в раскрываемой
  «Диагностике поиска». Повторный поиск обновляет данные, а поиск по сайтам
  доступен отдельной кнопкой.

## Проверка в установленном приложении

Проверена подписанная сборка `/Applications/Чушпан.app` 0.3.13 (26), исходный
коммит `9488387`. Для проверки использовался отдельный профиль с регионом EE.
Контрольные суммы таблиц личной медиатеки совпали до и после установки.

Оба произведения запущены через «Найти и смотреть» из карточек во встроенном
плеере. Чушпан подтвердил воспроизведение и сохранил растущую позицию.

- «Сита поёт блюз» — длительность 4891,19 с, сохранённая позиция выросла
  с 18,02 до 22,03 с. [Полнометражный фильм в Internet Archive](https://archive.org/details/Sita_Sings_the_Blues)
- «Каминандес», S01E01 — длительность 90 с, позиция выросла с 10,21 до 12,21 с.
  [Полная серия в Internet Archive](https://archive.org/details/Caminandes1LlamaDrama)

Диагностика Playwright в установленном приложении также запустила полную
серию «Каминандеса». В отчёте в настройках медиатеки `currentTime` вырос
с 0,383 до 2,188 с. Отчёт сохранился локально.

В карточке «Последнего королевства» S01E01 Чушпан показал страницу Plex с
подтверждённым номером серии и вынес вероятные совпадения в ручную проверку.
Технические причины были свёрнуты, включая HTTP 403 Kinogo и ограничение
фонового поиска Filmix через robots.txt.

Отдельная проверка Playwright на публичных страницах:

- Plex вернул HTTP 200. Номер серии совпал по адресу и структурированным данным.
  В проверенном DOM нет HTML5-видео и iframe. [Plex, S01E01](https://watch.plex.tv/show/the-last-kingdom/season/1/episode/1)
- Apple TV US вернул HTTP 200. Один признак номера серии, один iframe, ни одного
  доступного HTML5-видео. [Apple TV US, страница эпизода](https://tv.apple.com/us/episode/episode-1/umc.cmc.2lwdzvpttqf3dt4kuz3kjbshk?showId=umc.cmc.5lmpml3t4rlgc109wisldqf12)
- Публичная форма Filmix нашла страницу сериала. HTTP 200, сезон и серия не
  подтверждены, HTML5-видео и iframe не обнаружены. [Filmix, страница сериала](https://filmix.gg/seria/drama/102209-v-novi-2x-poslednee-korolevstvo-2015.html)
- Прямая фоновая проверка Kinogo получила HTTP 403. Публичная страница в
  изолированном браузере ответила HTTP 200, в одном из iframe обнаружен
  HTML5-плеер. Соответствие эпизоду и полное видео не подтверждены.
  [Kinogo, страница сериала](https://kinogo.is/4748-poslednee-korolevstvo.html)

На этих четырёх страницах Playwright не подтвердил полное видео и не измерил
движение `currentTime`. Регион в диагностике — EE, география внешнего IP
отдельно не подтверждалась. По ответам сайтов нельзя установить доступность
полного видео для Эстонии.

Через установленный backend проверены повторный поиск S01E01, отдельный поиск
по сайтам, поиск фильма и другого сериала, публичный HTTP 403 и задержка,
вызвавшая `ReadTimeout`. Для S01E01 сохранилась тестовая позиция 37 с,
не появилось новых ссылок. Найденные адреса в результатах не дублировались.

Десять последовательных поисков вымышленного фильма без результата и отмена
одиннадцатого после создания служебной вкладки оставили ноль временных вкладок.
Адреса и порядок 17 исходных вкладок в четырёх окнах Safari совпали после
каждого сценария. Штатный выход после появления служебной вкладки также
оставил исходные окна и вкладки на месте.

Проверки кода — 247 тестов медиатеки в Python, 194 теста фронтенда, Ruff,
проверка типов, сборка Vite и строгая проверка подписи macOS.
