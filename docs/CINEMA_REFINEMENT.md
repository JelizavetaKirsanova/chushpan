# Кинотека Чушпана 0.2.7 · доработка 4 ноября 2026

Этот этап продолжает существующую медиатеку. Каталог TMDB, SQLite, HudBus,
локальный маршрутизатор команд, адаптеры источников и плеер сохранены.
Интерфейс написан на TypeScript с прямым обновлением DOM; React в этом разделе нет.

## Что изменено

- Каталог открывается адаптивной сеткой с постерами 2:3. Горизонтальные подборки
  доступны отдельно. Стабильные ключи `tmdb:<movie|tv>:<id>`, добавление страниц
  в конец, дедупликация и сохранение DOM карточек продолжают работать.
- Новая боковая панель фильтров: несколько жанров OR/AND, диапазон годов,
  минимальный рейтинг, тип, страна производства, язык оригинала, счётчик,
  применение/сброс и чипы. Незавершённые изменения панели не запускают запросы.
  Применённые жанры, диапазоны и прочие параметры сохраняются в SQLite;
  поисковый текст и номер страницы в постоянные настройки не записываются.
- По умолчанию включены кириллица в названии, исключение Animation/16 и аниме;
  документальные/99 можно скрыть отдельно. Язык метаданных TMDB остаётся `ru-RU`.
  Страна происхождения не используется как замена языку названия.
- Аниме определяется по явным keywords либо сочетанию Animation и Японии.
  Все японские игровые фильмы не исключаются. При отсутствии нужных метаданных
  нельзя гарантировать идеальную классификацию. Для анимационных кандидатов
  при необходимости запрашиваются кешируемые подробности.
- Ограничения действуют в каталоге и подборках, включая отдельный пересмотр.
  Личные списки при этом остаются полными; записи не удаляются.
  В ручном поиске можно временно включить поиск без этих ограничений.
- Карточка фильма/сериала получила backdrop, постер, раздельные рейтинги,
  основные действия и вкладки «Где смотреть / О фильме / Похожие».
  Доступны режиссёры, актёры, страна, жанры, длительность и оригинальное название.
  Если данных нет, интерфейс явно сообщает об этом.
- Поиск источников теперь отображается внутри вкладки карточки. Сезоны, серии,
  озвучка, прогресс, устройство и ручная коррекция сохранены; дополнительные
  параметры раскрываются по запросу.
- Отдельное окно личной оценки: 1–10 с шагом 0.5, половинные звёзды, ползунок,
  заметка до 2000 символов, сохранение и удаление оценки. Рейтинг TMDB,
  личная оценка, статус и избранное независимы. Пересмотр сохраняет оценку и заметку.
- В личных списках добавлена сортировка по году. В рекомендациях появилась
  отдельная подборка «Пересмотреть любимое». Профиль дополнен графиком активности.
- В настройках рекомендаций независимо включаются оценки, избранное и история;
  персонализацию можно отключить. Ранжирование остаётся локальным, без платных AI API
  и выдуманных процентов совпадения.

## Настройки и TMDB

Настройки медиатеки разбиты на пять разделов с боковой навигацией:
Каталог, Источники просмотра, Воспроизведение, Рекомендации, Приватность и данные.
Добавлены сортировка по умолчанию, число колонок на большом экране и переключатель
продолжения с сохранённого места. На узком экране колонки адаптируются автоматически.

Источники представлены компактным списком с приоритетом, состоянием,
переключателем, предпочтением и раскрываемыми действиями. Работают перетаскивание,
кнопки порядка, редактирование, проверка и удаление. Добавление URL не требует кода.

**Форма интеграции TMDB убрана из интерфейса источников просмотра.**
Техническая настройка теперь открывается отдельно:
Общие настройки → Интеграции → Медиатека → Расширенные настройки интеграций →
Техническая настройка TMDB. Ключ не отображается в открытом виде.
Сам TMDB API, существующий файл ключа и его использование не удалены.
Каталог, постеры, метаданные, похожие произведения и рекомендации продолжают
использовать прежний официальный клиент, очередь запросов и кеш.

## Локальные данные, экспорт и импорт

Миграция 5 добавляет `cinema_library.user_note` и индекс истории. Старые строки
названий, оценок, источников, истории, эпизодов и прогресса не пересоздаются.
Общий `PRAGMA user_version` не изменяется.

В разделе «Приватность и данные» доступны просмотр локальных записей,
очистка кеша TMDB и кеша поиска источников, экспорт и импорт JSON-копии.
Копия содержит личные списки, оценки, заметки, источники/ссылки, историю,
эпизоды, позиции и настройки медиатеки. Ключ TMDB и другие данные ассистента
в копию не входят. Ссылки и заметки остаются личными данными: файл нужно хранить приватно.

В установленном приложении экспорт использует нативный Save panel, атомарную
запись и права `0600`; сохранение внутри Git-проекта запрещено. В браузере
используется обычное скачивание JSON.

Импорт ограничен 5 МБ и сначала показывает состав копии. Записи проверяются
до любых изменений: схема, типы, даты, оценки, эпизоды, ссылки, принадлежность
ссылки источнику и взаимные связи. Подтверждение связано с одноразовым токеном
предпросмотра, действующим 10 минут. Изменения выполняются одной транзакцией.

Импорт добавляет отсутствующее, сохраняет текущие оценки, заметки, статусы,
позиции, существующие ссылки и приоритеты. Настройки копии восстанавливаются
только при пустой медиатеке. Повторный импорт не дублирует историю и не создаёт
несуществующую первую серию, если сериал начинается с другого эпизода.
При ошибке SQLite вся транзакция откатывается.

## Голосовые команды и подтверждения

К прежним командам добавлены локальные обработчики:
«добавь этот фильм в избранное», «поставь этому фильму девять»,
«поставь этому фильму девять с половиной». Используется открытая карточка либо
активный плеер; без контекста нужно выбрать название. Обработчики выполняются до LLM.

Открытие страницы по-прежнему не называется запуском фильма. Встроенный плеер
подтверждает воспроизведение движением времени; внешняя позиция не угадывается.
Для полноэкранного просмотра в WebKit используется существующий нативный мост.

## Исправления и проверка

Сохранена ранее исправленная причина скачков: прежние страницы не пересортировываются,
не вырезаются из списка при шестой странице и не пересоздают постеры при снимках HUD.
Новые изменения дополнительно игнорируют устаревший ответ подробной карточки:
он не открывает уже закрытое окно и не подменяет более поздний выбор.

Проверены восемь страниц каталога, порядок и прокрутка после закрытия карточки
и перехода в избранное, несколько жанров, оценка 9.5 с заметкой, похожие фильмы,
раздельные настройки, перетаскивание сайтов, экспорт/повторный импорт через UI,
встроенное немое видео, пауза/перемотка, SQLite после перезапуска и мобильная ширина.

На временных копиях баз установленного приложения и проекта подтверждены сохранение
всех исходных строк при миграции, идемпотентный повторный импорт, `integrity_check`
и `foreign_key_check`. Исходные базы этими проверками не менялись.

Результаты завершённого прогона:

- **2241 Python-тест**, **106 UI-тестов** — успешно.
- Ruff, проверка форматирования, `git diff --check`, TypeScript и Vite — успешно.
- `--catalogue --personal` в Chromium: восемь страниц, стабильность прокрутки,
  фильтры, оценка с заметкой, похожие фильмы, профиль, порядок источников,
  экспорт/импорт и настоящий HTML5-плеер на немом тестовом видео — успешно.
- macOS 0.2.7, сборка 9: сборка, `codesign --verify --deep --strict`, проверка
  отсутствия личных файлов в пакете — успешно. Модули в PYZ и frontend assets
  отдельно сопоставлены с проверенными исходниками.

Нативный Save panel и полноэкранный мост проверены на уровне кода/моков;
реальные Safari Apple Events, микрофон, телевизор и внешние сайты этим этапом
не запускались. Браузерные проверки используют настоящий headless Chromium,
временную SQLite, mocked TMDB/HTTP и синтетическое немое видео. Это не подтверждает
совместимость каждого внешнего сайта и кодека WebKit.

## Реальные ограничения источников

Сохраняется рабочая система из [предыдущего этапа](PERSONAL_CINEMA.md):
автоматическое сопоставление через официальный API Internet Archive; для других
сайтов — точная пользовательская ссылка, разрешённый HTML5 либо поисковая страница
и ручной выбор. Для сериалов без поддерживаемого API структура эпизодов не угадывается.
Прямое совместимое видео встраивается только при разрешении источника.
Универсального извлечения потоков из Kinogo, Filmix и произвольных доменов нет.
DRM, CAPTCHA, платный доступ и авторизация не обходятся.

Подробности TMDB, включая диапазоны дат, жанры и AND/OR, сверены с
[официальным Discover API](https://developer.themoviedb.org/reference/discover-movie).
Поля подробностей загружаются через
[официальный Details API](https://developer.themoviedb.org/reference/movie-details).
