# Промежуточные реплики Чушпана

Старый источник: RU.one_moment в backend/i18n.py — «Ой, ну ща.».
Conversation добавлял её строкой в выходной поток при
долгом ожидании модели или перед slow-инструментом. В русской ветке эта
подстановка удалена: ожидание больше не является частью основного текста.
Поле локали оставлено для совместимости с другими языками.

backend/audio/waiting.py содержит 18 реплик, в том числе «Секунду», «Так,
щас», «Ща гляну», «Бля, щас», «Ща, не мешай гению работать». WaitingPhrases
случайно выбирает реплику, исключая последние четыре. По измеренной длине
кеша группа до двух секунд получает вероятность 70%, более длинная — 30%.
Если группа временно исчерпана исключением повторов, выбирается доступная;
если доступных клипов нет, ожидание молчит.

Голос Silero и выбранный speaker не меняются. При старте голосового режима
18 аудиофрагментов синтезируются в RAM один раз. Они не расходуются при
воспроизведении и не пересинтезируются на каждом запросе. Сбой подготовки
не запрещает основной голосовой режим: недоступные вставки пропускаются.

Для русских ответов reply_aloud запускает генерацию ответа отдельной задачей.
Если первый текст или завершение ответа получены раньше tools.one_moment_after_s
(сейчас 1.5 с), вставка не воспроизводится. Иначе запускается только готовый
клип. Первый основной текст прерывает вставку; полного окончания фразы ждать
не требуется. Worker проигрывания останавливается до повторного использования
того же Speaker, чтобы старый клип не продолжился после очистки stop-флага.
Размер блока проигрывания — 50 мс; аппаратная задержка зависит от аудиодрайвера.
Гарантия нулевой задержки вывода звука не заявляется.

Промежуточная реплика не поступает в Gemini, поток текста ответа, историю
диалога или on_sentence основного ответа/HUD. Основная обработка продолжает
работать во время вставки. На один запрос допускается максимум одна вставка.
Отмена/ошибка запроса освобождает задачи и восстанавливает callback.

## Измерение без воспроизведения

31 октября 2026, текущая локальная Silero: подготовка 18 клипов с загрузкой
заняла 2.575 с. Из них 14 короче двух секунд (0.70–1.66 с), четыре —
2.25–2.34 с. Кеш подготавливается при старте, а не на критическом пути каждого
запроса. Этот замер не измеряет задержку физического аудиоустройства.
Torch выдал SyntaxWarning из существующего пакета Silero об escape-последовательности;
синтез всех клипов завершился успешно. Файлы модели не менялись.

Логи WAIT_AUDIO_CACHE показывают количество/время подготовки,
WAIT_AUDIO_START — длительность выбранного кешированного клипа,
WAIT_AUDIO_END — время до завершения ожидания вместе с ожиданием модели.

Проверки: выбор без последних четырёх повторов, распределение длительностей,
мгновенный ответ без вставки, прерывание зависшей вставки готовым ответом,
ошибка модели, пропуск отсутствующего кеша, отсутствие вставки в тексте/HUD,
повторное использование Silero-аудио без повторного синтеза и остановка
worker перед основным ответом. Системные команды и реальное воспроизведение
в автоматических тестах не выполняются.

Для ручного прослушивания перезапустить обычный экземпляр Чушпана. Быстрый
локальный ответ не должен содержать вставку; при задержке ответа более 1.5 с
должна звучать одна из разных реплик. Основной ответ может оборвать её.
.env, ключи, память, личность и голосовая модель не изменялись. Commit/push нет.
