# Safari Web Inspector для Чушпана

Главное окно — `WKWebView` внутри pywebview (`backend/desktop/app.py`). Перед первой навигацией синхронный обработчик `before_show` на главном потоке Cocoa задаёт публичное свойство `inspectable` через PyObjC `setInspectable_`. Нужны macOS 13.3+ и Safari с включёнными функциями разработчика.

## Запуск из исходников

В корне существующего checkout с установленными зависимостями и собранным `frontend/dist`:

```sh
.venv/bin/python -m backend.desktop --no-auto-listen
```

У запуска из исходников (`sys.frozen` отсутствует или false) инспектирование включено автоматически. `--no-auto-listen` запрещает автоматическое включение микрофона в этом запуске и не меняет сохранённые настройки. Остальные действия при запуске подчиняются настройкам выбранного профиля.

Для отдельного тестового профиля задайте `CHUSHPAN_APP_DATA` перед командой; не используйте личный профиль для экспериментов с DOM или JavaScript. Если интерфейс менялся, перед запуском выполните `npm --prefix frontend run build`. Полная сборка, установка и подпись production-приложения для этой проверки не нужны.

## Упакованное приложение

В production (`sys.frozen == true`) инспектирование выключено. После попадания этой правки в очередную сборку его можно включить только явно, на один запуск:

```sh
open -a '/Applications/Чушпан.app' --args --developer-mode --no-auto-listen
```

Сначала завершите уже работающее приложение через его меню: аргументы не применяются к существующему процессу. Следующий обычный запуск снова отключает инспектирование. Флаг не сохраняется в настройках и не включает pywebview `debug`, автоматическое открытие DevTools или отдельный сетевой порт отладки. Установленная до этой правки версия ещё не поддерживает флаг.

## Подключение и проверка

1. В Safari → Настройки → Дополнения включите «Показывать функции для веб-разработчиков» (название зависит от языка Safari).
2. Запустите Чушпана указанной выше командой и дождитесь загрузки интерфейса.
3. Откройте Safari → Разработка → **Inspect Apps and Devices** (в проверенной русской версии — «Просмотреть код приложений и устройств»). Выберите текущий Mac и страницу приложения. При запуске из исходников хост называется **Python**, страница может отображаться как **127.0.0.1**, а не по заголовку. Проверить, что это Чушпан, можно по `document.title` в консоли. Альтернатива — подменю текущего Mac в меню «Разработка».
4. Откройте инспектор страницы. На вкладке **Elements** выберите узел DOM или включите выбор элемента и нажмите на элемент в окне Чушпана. Проверьте `class`, CSS-правила в **Styles**, итоговые свойства в **Computed** и box model с размерами, `margin`, `border`, `padding`.
5. В **Console** выполните безопасное выражение `document.title`; во вкладке **Sources** доступны загруженные JavaScript-файлы. Production-файлы интерфейса могут быть минифицированы.
6. Закройте инспектор и завершите тестовый запуск. Изменения DOM/CSS в инспекторе временные; выполнение JavaScript может вызывать обычные действия приложения.

В журнале выбранного профиля `data/logs/desktop.log` строка `DESKTOP_WEB_INSPECTOR enabled=True` подтверждает применение свойства к реальному WKWebView; подключение Safari и выбор DOM нужно проверять отдельно. Если страницы нет в списке, проверьте режим запуска, версию macOS, загрузку окна и функции разработчика Safari.

Основа реализации: [публичное свойство WebKit isInspectable](https://webkit.org/blog/13936/enabling-the-inspection-of-web-content-in-apps/) и [Inspect Apps and Devices в Safari](https://developer.apple.com/documentation/safari-developer-tools/inspect-apps-and-devices).

## Выполненная проверка 17 ноября 2026

На macOS 26.6.2 / Safari 27.2 запущено реальное development-окно с `--smoke --no-auto-listen` на пустом временном `CHUSHPAN_APP_DATA`. В Inspect Apps and Devices обнаружен **Python → 127.0.0.1**. Подключён Web Inspector, в дереве Elements выбран `div.hud`, доступны CSS-правила из загруженного файла, Computed и box model (`1291 × 868`, padding `0px`). В Console выполнены `document.title` и чтение класса, ширины и padding через DOM / `getComputedStyle`; заголовок — «Чушпан · Ассистент». Переключатель выбора элементов включается; отдельный выбор мышью поверх окна автоматизированной проверкой не подтверждён. Тестовый процесс завершён, уже работавшее установленное приложение не перезапускалось. Production-сборка и установка не выполнялись; политика production по умолчанию / явного включения проверена тестами.
