# Обучение воспроизведению в Safari

Сквозная проверка установленного приложения пока не пройдена. Страница и
выбранный iframe открываются, но macOS не подтверждает Accessibility-доступ
процессу установленного Чушпана. Отдельные живые проверки адаптера из процесса
разработки воспроизвели S01E01 и S01E02. Эти результаты имеют разную область проверки.

В Safari контрольная страница открылась в существующей браузерной сессии. На
странице есть «Смотреть онлайн», «Плеер 1» и «Плеер 3». При прокрутке и выборе
«Плеера 1» сайт подгружает iframe `api.nextembed.ws` с видимыми полями сезона,
серии и озвучки. Safari JavaScript верхней страницы получает `contentDocument =
null` для этого iframe. Изолированный Chromium через Playwright получил HTTP 403
с заголовком «Just a moment…». Эти два ограничения объясняют, почему прежний
HTML5-адаптер не мог повторить действия пользователя.
[Контрольная страница](https://kinogo.online/serialy/33039-poslednee-korolevstvo.html)

Ручная проверка Safari показала первую серию с озвучкой LostFilm и длительностью
59:02. Видимый таймер вырос с 00:04 до 02:12. Новый адаптер выбирает вкладку
плеера в DOM, затем пользуется видимыми элементами Safari через macOS
Accessibility. Он сверяет выбранный эпизод и длительность, измеряет движение
таймера и ограничивает действия отмеченной вкладкой и одним iframe. JavaScript
`currentTime` из этого iframe недоступен. Автоматизация работает в обычной
браузерной сессии с её существующим доступом.

В карточке произведения вкладка «Где смотреть» содержит «Научить Чушпана
смотреть на этом сайте». В форме можно изучить публичную страницу HTTPS,
указать вкладку плеера и озвучку и запустить проверку. Чушпан сохраняет
сценарий после подтверждения видео, не отмечая диагностический запуск в
истории просмотра. Изменение сценария проходит повторную проверку.
При обычном «Найти и смотреть» Чушпан сначала пробует сохранённый сценарий
и проверяет именно выбранную серию.

Проверена подписанная сборка `/Applications/Чушпан.app` 0.3.14 (27)
с исходным коммитом `bd1325d`. Проверка кода прошла — 250 тестов медиатеки,
194 теста интерфейса, Ruff, TypeScript и сборка Vite. Повторены 17 целевых тестов
после исправления ожидания динамических полей сезона и серии.

Учебное окно получает уникальную метку во фрагменте адреса. Safari может
добавить зеркало закреплённой вкладки в новое окно. Менеджер запоминает
начальный состав и закрывает созданное окно целиком, если состав прежний,
а исходные вкладки присутствуют в других окнах. При добавлении новой вкладки
пользователем закрывается только отмеченная вкладка Чушпана.

Универсальный доступ проверяется в контексте установленного приложения.
Разрешение процесса разработки не подтверждает доступ установленной сборки.
Включённый переключатель в системных настройках не совпал с результатом
публичного API из установленного процесса. С разрешения пользователя добавлен
встроенный исполнитель `ytmusic_ax`, обновлены его запись и переключатель,
приложение перезапущено. Последняя проверка backend всё ещё вернула
`accessibility: check_needed`. Проверка сохраняет конкретную причину отказа
и убирает учебное окно. Локальная сборка имеет ad hoc подпись, доступных
идентичностей подписи разработчика в связке ключей не найдено. Связь отказа
с идентификацией локальной подписи требует дальнейшей проверки.

В диагностике из процесса разработки S01E01 с LostFilm показала рост видимого
таймера с 00:00 до 00:01, длительность 59:02. Для S01E02 выбран пункт «2 серия»,
таймер вырос с 00:01 до 00:02, длительность 58:42. Отдельная исходная ручная
проверка первой серии показала кадры произведения и рост до 02:12.

В установленной сборке проверены обе серии. Для каждой подтверждены открытие
точной страницы и обнаружение выбранного iframe `api.nextembed.ws`. Выбор
серии и движение таймера остановились на отказе Accessibility. Сценарий
не записан как рабочий. Тестовый прогресс первой серии остался равен 37 с,
личные таблицы медиатеки совпали по контрольным суммам до и после обновления.

Редактор сценария позволяет изменить URL, название вкладки плеера и озвучку.
Сохранённый сценарий проверяется при повторном просмотре до общего поиска.
Автоматическое восстановление произвольного таймкода и полноэкранный режим
для этого iframe пока не реализованы. Их можно выбрать в самом плеере сайта.
JavaScript `currentTime` для междоменного iframe не измерялся, движение видео
в успешных проверках определялось по доступному таймеру интерфейса Safari.

Десять последовательных отказов учебного запуска в установленном приложении
завершились без временных вкладок и новых видимых окон. После каждого сценария
сохранились те же шесть исходных окон с 23 вкладками, включая их адреса и порядок.
Отмена после появления отмеченной вкладки также прошла эту проверку.
Ранее существовавшие окна без метки владельца автоматически не закрывались.

Рабочие данные сценариев хранятся в `cinema_site_recipes` той же SQLite-базы.
Связанные изменения находятся в `learned_player.py`, `browser_search.py`,
`service.py`, `store.py`, нативном `ytmusic_ax.swift` и интерфейсе `cinema.ts`.
Диагностические экспорты и тестовый профиль сохранены вне исходников.

`AXIsProcessTrusted` проверяет доверие к текущему процессу. Это объясняет,
почему результат из среды разработки нельзя переносить на установленное
приложение. [Документация Apple](https://developer.apple.com/documentation/applicationservices/1460720-axisprocesstrusted)
