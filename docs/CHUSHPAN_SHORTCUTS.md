# Apple Shortcuts: настройка, этапы 4–5

Команды обнаруживаются штатным `/usr/bin/shortcuts list --show-identifiers`.
Запуск — `shortcuts run UUID --input-path ... --output-path ... --output-type public.utf8-plain-text`.
Это поддерживаемый [интерфейс Apple](https://support.apple.com/en-gb/guide/shortcuts-mac/apd455c82f02/mac).
Ассистент не создаёт, не импортирует, не подписывает и не редактирует существующие Shortcuts.

## Разрешённый реестр

Базовая модель конфигурации имеет пустой allowlist. В конфигурации этого Mac после
проверки редактора разрешена только `Youtube sleep`, UUID
`1646EE92-B628-481D-9499-CED5B05EC32D`. Обнаружение команды само по себе не разрешает запуск.
На этом Mac найдены: Youtube sleep, Новая команда 2, Новая команда 1, Новая команда,
Take a Break, Text Last Image, Shazam shortcut, What’s a shortcut?. Ни одна не запускалась
в ходе разработки. Другие команды не разрешены. Название не доказывает безопасность действий.

Проверенный `Youtube sleep` содержит AppleScript: каждые 5 секунд читает
`video.ended` в активной вкладке переднего окна Safari и после окончания усыпляет Mac.
Он не открывает YouTube и не запускает музыку сам. Если видео нет/оно бесконечное,
ожидание может не завершиться. Safari Automation/JavaScript from Apple Events и
System Events должны быть доступны по решению пользовательницы, права не менялись.

В ночном сценарии применяется отдельный фиксированный порт запуска этой команды:
после общего подтверждения/Agent gate, повторной проверки UUID, с очищенным env и
сохранённым журналом. Он возвращает статус **начала ожидания**, не ждёт окончания
видео и не повторяет запуск. Обычный `run_shortcut` сохраняет прежний ограниченный
синхронный путь. [Приёмка, остановка и сброс журнала](CHUSHPAN_STAGE5_REPORT.md).

Порядок ручной настройки:

1. Открой нужную команду в приложении «Команды» и проверь **все** действия,
   вложенные «Запустить команду», shell/AppleScript, сетевые адреса и запросы данных.
   Не разрешай команды, которые интерпретируют входной текст как код.
2. Получи точный UUID через `shortcuts list --show-identifiers`.
3. Добавь в `config.yaml` запись следующего вида, заменив пример реальным ID:

   ```yaml
   shortcuts:
     allowed:
       Учёба:
         identifier: 12345678-1234-1234-1234-123456789abc
         description: Включить фокус Учёба и открыть выбранные учебные приложения
         input_type: none
   ```

4. Допустимы `none`, `text` и `url`. Для `url` принимается HTTP(S) без учётных данных;
   сетевые последствия проверенной команды остаются частью её разрешения.
   Текст ограничен 1000 символами; вход должен буквально присутствовать в текущей
   просьбе. Произвольные пути и исполняемые параметры не принимаются.
5. Перезапусти ассистента после изменения конфигурации. Скажи «Запусти Учёба»;
   проверь описание и подтверди свежий код в течение 90 секунд. Простое «да» не запускает.

UUID предотвращает подмену одноимённой командой. Перед каждым запуском перечитывается
список и проверяется пара имя/ID. Смена ID/описания/типа входа отменяет прежнее согласие.
Редактирование действий внутри Shortcuts может сохранить тот же UUID: CLI не даёт
контракт проверки содержимого. После такого редактирования нужна новая ручная проверка.
Реестр и код подтверждения не являются песочницей для самих Apple Shortcuts.

Вход передаётся в приватном временном файле, без shell; переменные API-ключей не
наследуются дочерним CLI. Временные файлы удаляются. Вывод ограничен 64 КиБ,
в ответе — 4000 символов; двоичные результаты не выдаются за текст. Названия и вывод
считаются недоверенными данными. Вывод не запускает другие инструменты.
Тайм-аут/ошибка не откатывают уже выполненные действия Shortcuts. Убийство CLI не
гарантирует отмену внутри macOS; автоматического повтора нет.

## Проект «Учёба»

Ручная последовательность в Shortcuts, до создания и включения пользовательницей:

1. Настроить действие фокусирования «Учёба» в macOS. В ассистенте отдельного Focus tool нет.
2. Добавить открытие **выбранных** учебных приложений. Существующий `open_app`
   уже выполняет явную команду на Mac; нельзя автоматически открывать угаданный список.
3. Выбрать реальный учебный плейлист. Есть `music_playlist`/`play_music`/`media_control`
   YouTube Music, но сценарный плейлист сейчас не назначен. Назначение — через существующее
   подтверждение; отсутствие плейлиста нельзя подменять сообщением «музыка включена».
4. Ближайшие учебные задачи — заблокированный шаг до памяти/источника задач этапов 5/8.
   Не использовать выдуманный список или личный календарь вместо задач без согласия.

Готовность: пользовательница выбрала приложения и плейлист, вручную проверила действия,
разрешила UUID; живой запуск подтвердил каждый доступный шаг. Незавершённые шаги пропускаются
с ясным сообщением, а не возвращают фиктивный успех.

## Проект «Сон»

Ручное действие «Фокусирование → Сон» по настройке macOS. Музыка — явно выбранные
pause/stop в уже существующем медиапути. `go_to_sleep` означает ожидание ассистента,
`mac_power(sleep)` — сон самого Mac с отдельным подтверждением: не смешивать эти состояния.
Существующий Youtube sleep не исследован изнутри и не разрешён по одному названию.
Выключение света — будущий шаг этапа 11; HomeKit/Home Assistant здесь не реализованы.

Готовность: проверен выбор режима и плеера, нет неожиданного сна/выключения Mac;
свет помечен недоступным до подключения реального устройства.

## Проект «Выход из дома»

Погоду можно получить через действующий `get_weather` с настроенным городом либо явным
городом запроса. Календарь существует только внутри утреннего EventKit-сценария;
отдельного LLM-инструмента ближайшего события нет. В Shortcuts пользовательница может
сама выбрать календарь и разрешить его чтение, но эта настройка ещё не выполнена.
Маршрут/место назначения и состояние умного дома требуют отдельных настроек/интеграций.
`get_system_status` описывает Mac, а не все домашние устройства.

Готовность: источник и часовой пояс события проверены, выбран маршрут, каждое устройство
имеет реальную интеграцию. Сейчас это проект с доступным погодным шагом.

## Проект «Запомни это»

Будущий Share Sheet получает выбранный текст или URL, показывает точное содержимое и
источник. Сервер проверяет размер, тип, секреты и недоверенные инструкции; **не загружает
URL автоматически**. Далее — явная просьба `remember` и существующее device/session
подтверждение конкретного факта. Ответ из Shortcut не может сам дать согласие.
Сейчас можно вручную передать проверенный текст в локальный чат. HTTP endpoint записи
из Shortcuts не создан; clipboard/выделение не читаются автоматически.

Готовность: авторизованный транспорт и pairing, просмотр факта до записи, revoke,
тесты повторной отправки и ошибочного источника. Не хранить сам документ целиком.

## Проект «Продолжим на Mac»

Будущий сервер принимает task ID и краткое содержание от уже привязанного устройства,
проверяет владельца, срок действия и доступность целевого Mac Agent. Просмотр задачи
не разрешает запуск приложения/действия; для них нужен отдельный актуальный запрос.
Используется общая память, без пересылки SQLite. При недоступном Mac — явная ошибка,
а не выполнение на другом сервере. Транспорт передачи задачи пока отсутствует.

Готовность: защищённый message API, pairing/revoke, request ID/идемпотентность,
heartbeat Agent и проверенная передача между реальными устройствами.

## Будущая команда «Спросить Чушпана»: iPhone/iPad

Проект интерфейса для этапа 7:

1. Пользовательница запускает Shortcut через приложение, Siri или виджет согласно
   возможностям и ограничениям установленной iOS/iPadOS. Голосовой ввод разрешается
   явно; диктовка Apple не гарантированно локальна и отличается от Whisper на Mac.
2. «Запросить ввод»/диктовка → текст; сформировать JSON с текстом и request ID.
   Для изображения — только явно выбранное вложение, с лимитами размера и согласия.
3. HTTPS-запрос к разрешённому серверу через частную сеть/Tailscale после реализации
   этапа 7. Нужны pairing, ограниченный device token, срок жизни и revoke. Не встраивать
   постоянный административный токен в экспортируемую или общую команду. Отдельное
   приложение не планируется: pairing-код, показанный на Mac, может открывать короткую
   сессию; её scoped token хранится только в переменных текущего запуска Shortcut.
   Нельзя предполагать прямой доступ стандартных Команд к произвольному Keychain.
4. Сервер проверяет токен и сам создаёт `DeviceContext`/capabilities/session;
   присланные `device_id`, `authenticated` и текст изображения не создают полномочий.
5. Показать текст ответа или вызвать «Произнести текст» на устройстве. Код опасного
   действия проверяет тот же сервер в той же сессии; повтор не дублирует действие.

Это **проект**, работающего мобильного endpoint/токенов/Tailscale ещё нет. Существующий
HUD остаётся на loopback. Сервер не может сам удалённо запускать произвольные команды
на iPhone; запуск инициирует пользовательница/разрешённая автоматизация самой iOS.

## Вложения iPhone/iPad

`ImageInput` — внутренние bytes/MIME/source без файлового пути устройства и без
сохранения в SQLite. В будущем сервер должен проверить авторизацию загрузки, реальный
формат/размер/число пикселей, source и привязку к запросу, ограничить TTL и повторы.
Клиентский `source=iphone` не является доказательством прав. Действия Mac требуют
адресного Agent grant; анализ изображения остаётся отдельным запросом без tool execution.
