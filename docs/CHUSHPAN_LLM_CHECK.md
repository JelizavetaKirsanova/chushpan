## Условия и границы проверки

Пять серий по семь запросов: 35 проверочных обращений. Каждый запрос серии
начинает новый диалог; это не оценка устойчивости в многодневной истории.
Использованы действующие `Conversation`, prompts, `OllamaClient` и реестр.
`think=true`, `temperature=0.6`, `num_ctx=16384`; только для пробы задан
предел `num_predict=1200`. Один пустой ответ после достижения этого предела
в третьей серии вызвал предусмотренную кодом повторную генерацию.
Время включает обработку запроса и раунд инструмента, это не чистая скорость токенов.

Память — отдельная `:memory:` для каждой пробы. Вместо настоящего Mac внедрён
подставной Agent: открытие приложения возвращает синтетический успех, заряд —
18%, без подключения питания. Ни одно приложение реально не открывалось;
музыка, системные настройки, микрофон, экран и личные факты не использовались.
Фраза «Ой, ну ща.» — существующая автоматическая реплика ожидания при задержке,
а не сгенерированная шутка модели. Она не записывается в историю; сохранена
совместимость существующего голосового поведения. Повтор этой фразы остаётся
заметным ограничением UX при медленной модели.

У модели обнаружен наследуемый `presence_penalty=1.5`. Четвёртая серия
временно переопределяла его в запросе на 0, без изменения `config.yaml`,
модели или production-клиента. Убедительного улучшения не получено;
эксперимент не принят. Итоговая пятая серия использует исходные параметры.
Сведения `/api/show` о template и renderer проверены: renderer/parser Qwen3.5
не потребовал смены template. Ollama, модель и рабочая конфигурация сохранены.

## Оценка результата

Речь стала короче и разговорнее; бытовая усталость получает короткую реакцию
с уместным «блин», тяжёлая ссора — серьёзный вопрос без подкола. Открытие
приложения и заряд используют верные инструменты. Сохранение останавливается
на коде подтверждения: фактов после запроса по-прежнему ноль.

**Полная стилистическая и фактическая приёмка не достигнута.** В итоговом Java-ответе
Qwen смешала неинициализированную локальную переменную (ошибка компиляции)
с null-ссылкой (возможная NPE при выполнении); также использовала мужское
«не инициализировал» и лишнее предложение помощи. Ответ о батарее содержит
неудачный упрёк; обычная беседа — натянутое сравнение с часами. Поддержка после
ссоры начинается с шаблонного «мне жаль». Системные инструкции этого не гарантируют.
Эти ответы сохранены ниже без исправления и не засчитаны как идеальные.

Успех тестов шаблонов доказывает наличие нужных инструкций и общий путь
чата/голоса, но не доказывает соблюдение их каждым ответом Qwen. Модель не
менялась, глобальные параметры ради красивой демонстрации не подбирались.
