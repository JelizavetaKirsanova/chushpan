# Диагностика STT — 31 октября 2026

До изменений эффективные настройки (прочитаны без вывода .env):
mlx-community/whisper-small-mlx, mlx-whisper, ru, temperature=0,
condition_on_previous_text=False. Русский уже задавался через язык ассистента;
автоопределение языка не было причиной ошибки.

PortAudio вне песочницы: MacBook Pro Microphone, индекс 0, одно входное
аудиоканальное устройство, штатная частота 48000 Гц. Приложение запрашивает
16000 Гц mono int16, блок 512 отсчётов (32 мс); CoreAudio/PortAudio выполняет
преобразование аппаратного формата. Whisper получает float32, делённый на 32768.
Проверка поддерживаемого формата прошла без открытия аудиопотока. Устройство
по умолчанию может смениться при подключении гарнитуры; диагностику повторить.

Silero VAD: threshold=0.5, release=0.35, до изменений start=96 мс,
min_speech=300 мс, silence=700 мс, preroll=300 мс, ограничение 30 с.
Слишком короткая команда могла быть отброшена. Хвост раньше обрезался до трёх
кадров (~96 мс); тихое окончание могло пострадать. Пауза >700 мс завершала
фразу. Это установленные свойства кода и риски, а не доказанный диагноз
конкретных пользовательских записей: микрофон для исследования не включался.

## Изменения

- Конфигурация: локальный mlx-community/whisper-large-v3-turbo, явный ru.
  Ранее в кеше был только small. Turbo скачивается при первом использовании;
  сетевой доступ нужен для загрузки весов, последующая обработка локальная.
- Для разговорных пауз silence=1000 мс; start=64 мс, min_speech=160 мс,
  preroll=400 мс и сохраняемый хвост 256 мс. Порог VAD не снижен.
  Цена: около 300 мс дополнительного ожидания и возможное увеличение ложных
  срабатываний на шум; для индивидуальной настройки нужны реальные фразы.
- Подсказка русского декодера дополнена YouTube, Safari, Gemini, Ollama,
  GitHub, BetterDisplay; имя Чушпан уже присутствовало. Это подсказка Whisper,
  она не переписывает результат. Задача явно transcribe, не translate.
- Счётчики переполнения входа/потерь кадров, причина завершения VAD.
- stt-check показывает модель, язык, устройство и формат. Без --record
  не открывает микрофон. При явной записи показывает длительность аудио,
  время загрузки и распознавания, исходный/отфильтрованный текст, RMS,
  насыщенные отсчёты и признаки возможного обрезания. Логи аудио не сохраняются.

Wake-word и его фраза, TTS, Gemini, инструменты и память не изменялись.
STT-модель и VAD используются также для существующей Whisper-активации;
поэтому её задержку нужно проверить вместе с командами после смены модели.
LLM не исправляет и не угадывает транскрипцию. Текст диагностики виден в терминале.

## Сравнение локальных вариантов

| Вариант | Совместимость и выбор |
| --- | --- |
| MLX small | Уже работал и кеширован; меньше нагрузка, исходная точка сравнения |
| MLX medium | Поддерживается текущим движком; промежуточный вариант |
| MLX large-v3-turbo | Рекомендуемый кандидат для M4 Pro: локальное ускорение Apple Silicon; качество и задержку измерить на тех же фразах |
| faster-whisper large-v3-turbo | Опциональный CPU int8 через CTranslate2; обычный upstream GPU-путь требует NVIDIA CUDA. Сейчас не установлен; зависимость не добавлялась |

Нельзя честно указать выигрыш WER или скорость без одной и той же записи
и эталонного текста. Замеров на пользовательском аудио пока нет.

Проверки: полный набор 896 passed; Ruff check и format --check прошли.
Новые тесты проверяют отсутствие записи по умолчанию, остановку микрофона
при таймауте, короткие команды и паузы, сохранение краёв, ограничение длины,
потери кадров, PCM → float32 и неизменность смешанной транскрипции.

Источники: https://github.com/ml-explore/mlx-examples/tree/main/whisper ,
https://huggingface.co/mlx-community/whisper-large-v3-turbo ,
https://github.com/SYSTRAN/faster-whisper .

## Запуск

Без записи:

```bash
cd ~/my-jarvis
uv run python -m backend stt-check
```

Только после согласия на запись: одна фраза, максимум 20 секунд, только RAM:

```bash
uv run python -m backend stt-check --record
uv run python -m backend stt-check --record --models mlx-community/whisper-small-mlx mlx-community/whisper-large-v3-turbo
```

Для опционально установленного faster-whisper можно добавить модель
`faster-whisper:large-v3-turbo` в тот же --models. Модели сравниваются на
одном массиве аудио, без запуска команд из распознанного текста.
Для начала: «Эй Чушпан, открой YouTube в Safari», «Проверь Gemini»,
«Стоп», «Да», «Поставь таймер… на десять минут». Для оценки ошибок записать
ожидаемый текст отдельно и сопоставить с выводом, включая отрицания и числа.

При 20-секундном таймауте незавершённая фраза не распознаётся; это явная
граница диагностического режима. max_duration и onset_at_buffer_start —
признаки риска, они не доказывают потерю слов.
