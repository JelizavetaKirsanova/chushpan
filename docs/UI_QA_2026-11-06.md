# Технический QA Чушпана — 6 ноября 2026

> Это отчёт отдельного QA-прохода. Его исторический статус `blocked` и сведения
> об установленной 0.3.4 не описывают финальную интеграцию памяти и RGB.
> Актуальные совместные проверки: [FINAL_INTEGRATION_2026-11-06.md](FINAL_INTEGRATION_2026-11-06.md).

Проверена существующая архитектура: TypeScript HUD → локальный WebSocket → Python-сервисы →
SQLite → ответ в HUD. Тёмно-фиолетовые цвета, навигация, карточки и оформление сохранены.
Физические команды устройствам и запись микрофона в этом QA не выполнялись.

## Найденные причины и исправления

1. **Сетка настроек.** Четыре ссылки («Управление Mac», «Синхронизация», «Личная аналитика»,
   «Приватность») создавались без блока иконки. CSS ожидал три колонки и помещал текст в
   44-пиксельную колонку иконки. Восстановлена та же структура icon/text/chevron; текстовые
   колонки используют `minmax(0,1fr)`.
2. **Повторный учёт аналитики.** Вызов `device_command` мог вызывать ещё один инструмент
   устройства, и оба попадали в одну категорию аналитики. Область наблюдения теперь исключает
   вложенный повтор той же категории, сохраняя отдельные команды и категории сценариев.
3. **Одинаковые показатели на разных вкладках.** Личная аналитика повторяла общий набор KPI;
   мини-графики четырёх KPI статистики использовали один ряд количества обращений. Вкладки
   показывают показатели своей категории; график обращений не выдаётся за ряд задержки или
   успешности. Отсутствующие измерения остаются отсутствующими, нулевой столбец имеет нулевую высоту.
4. **Фильтры аналитики.** Выбор своего периода терял устройство; быстрые изменения фильтров
   могли перекрывать друг друга. Выбранные фильтры объединяются, последний запрос ставится
   в очередь. Отмена возвращает подтверждённый период, неверный диапазон не отправляется.
5. **Неясные состояния загрузки.** Добавлены отдельные состояния первоначальной ошибки с
   повтором, отсутствия связи, пустого периода и отключённого сбора. Ошибка статистики снимает
   `aria-busy` с карточек. Превышение лимита 100000 событий больше не обрезает отчёт молча.
6. **Устаревшие ошибки аналитики.** Ошибка получения активности Mac сохранялась после
   восстановления native API. Ошибка выборки теперь очищается при успешной выборке, отдельно
   от ошибки хранилища. Политика сбора при этом не меняется.
7. **Удалённый каталог устройств.** Сервис синхронизации обращался к отсутствующему полю
   `Device.enabled`, вызывая ошибку ответа клиенту. Используется фактический снимок устройств
   и его признак доступности; наружу передаются только id, имя и тип.
8. **Ложный online после остановки.** Статус клиента зависел от старого `last_seen` и не
   учитывал работающий сервер. Online теперь требует живого сервера и запроса в текущем
   сеансе. Исторический контакт и сопряжения сохраняются.
9. **Жизненный цикл TLS.** Исправлены освобождение сокета при сбое, остановка после падения
   server task и немедленный повторный запуск. Занятый порт и неверный локальный IP объясняются
   пользователю. Последний подтверждённый endpoint сохраняется; автозапуск сервера не включается.
10. **Мастер сопряжения.** Диалог закрывался до получения QR. Теперь он обновляет QR и фазу
    сервера, сохраняет введённый адрес при ошибке и показывает сообщение backend внутри диалога.
    Использованы уже поддерживаемые операции запуска и остановки. Переподключение существующего
    клиента объясняется честно: подписанный запрос инициирует клиент Safari.
11. **Гонки операций.** У запросов новых модулей и ответов есть operation ID; устаревший ответ
    не заменяет данные. Отклонённый второй запрос получает свой ID и завершённое состояние.
    Периодический опрос синхронизации пропускает занятую операцию.
12. **Отключённые формы.** Поля модальных окон не блокировались при потере связи; после смены
    вкладки могли появляться снова активными. Состояние соединения применяется к новым полям
    и открытым диалогам. Остановка захвата остаётся доступной во время операции.
13. **Лишняя операция приватности.** Отмена захвата сопровождалась вторым запросом через
    произвольную задержку. Оставлена одна операция отмены: backend уже очищает превью.
14. **Даты и отсутствующие значения.** Наивные UTC-даты журналов/памяти корректно отображаются
    в локальном времени; неверная дата имеет явное состояние. Пустой объект метрик устройств
    больше не выводит `undefined мс`; действительный ноль не скрывается.

## Проверки и доказательства

- Полный Python-набор из изолированного checkout: **2541 passed**, 89.28 с. Локальные сокеты
  разрешены; внешние интеграции и устройства заменены тестовыми адаптерами.
- Полный frontend-набор: **162 passed**; TypeScript typecheck и production Vite build прошли.
- После добавления защиты Git повторный целевой набор Git + WebSocket: **47 passed**.
- Ruff: все проверки и форматирование 302 Python-файлов из QA-checkout прошли.
- Реальный HTTPS на `127.0.0.1`: проверены занятый порт, старт, подписанный запрос клиента,
  остановка и повторный старт на том же порту. CA временный, проверка сертификата включена.
  Сопряжение осталось; online восстановился после нового подписанного запроса.
- Автотест `test_ui_qa_transport.py`: настоящий маршрут HUD WebSocket, валидация запросов,
  временная SQLite, запись памяти, включение/выключение тестовой аналитики, фильтр устройства,
  JSON-экспорт, ошибка периода, восстановление и открытие той же БД новым экземпляром сервиса.
  Native API в этом тесте запрещён.
- Браузер: 10 основных страниц × ширины **580, 900, 1440, 1920, 2560** при высоте 1000.
  В 50 проверенных состояниях нет горизонтального переполнения документа и проверенных карточек.
- Пройдены 28 вкладок памяти/Mac/синхронизации/аналитики/статистики и 7 вкладок медиатеки.
  Все 14 категорий настроек открыты при 1440 и 580 px; поля при 580 px не выходят за viewport.
- Диалоги памяти, подключения устройства и своего периода: 580/900/1440 px, без горизонтального
  переполнения. Браузерный журнал после основного прохода: ошибок и предупреждений нет.
- Через UI сохранено тестовое воспоминание и проверено после reload. Native fixture Mac
  показал явно тестовое изображение и результат OCR через обычный backend, без захвата экрана.

Снимки и результаты геометрии находятся вне Git в каталоге визуализаций текущей QA-задачи.
Они не являются диагностическим экспортом пользовательских данных в исходники.

До проверки обе найденные копии имели 0.3.3 (16), commit `4c0601b`; работала копия из `dist`.
После закрытия старой копии установлена **0.3.4 (17)** в `/Applications/Чушпан.app`.
Она собрана в отдельном checkout от `6f65571` с перечисленными QA-исправлениями, исключая
незавершённую параллельную разработку памяти и RGB. `source_dirty=true` в манифесте отражает
эти дополнительные QA-исправления, а не чистый commit `6f65571`.

Проверен реальный процесс `/Applications/Чушпан.app/Contents/MacOS/Chushpan --no-auto-listen`
и его worker. В установленном окне открыты сценарии, устройства, кино, память, Mac,
синхронизация, аналитика, статистика и настройки. Кино дополнительно проверено снимком экрана:
WebKit accessibility в одном проходе не предоставил дочерние элементы этой страницы.
Микрофон в окне выключен. В последних 400 строках application.log после прохода — 0 traceback.

Перед установкой создана приватная копия SQLite и настроек. После запуска и навигации
побайтово/запросами проверено сохранение application preferences, политики аналитики и sync peers.

доступ не выдавался и настройки приватности не менялись. Поддержку оборудования и внешних
сервисов этот отчёт не объявляет подтверждённой.
