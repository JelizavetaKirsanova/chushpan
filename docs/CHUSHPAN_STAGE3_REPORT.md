## 2. Что добавлено и исправлено

`backend/mac.py:MacDesktop` и `backend/tools/mac.py:mac_tools` добавляют:

- `get_apps(scope=running|active)` — список запущенных/активное приложение.
- `manage_app(switch|quit)` — адресное переключение и обычное закрытие;
  без forceTerminate. Quit требует отдельный код. Имя не подменяется нечётким совпадением с другим продуктом.
  Bundle/PID сверяются перед
  операцией; завершение/активация проверяются чтением состояния.
- `get_windows` — список окон конкретного либо активного приложения.
- `manage_window` — focus, minimize/restore, left/right/maximize, move/resize,
  fullscreen/exit. Spaces возвращает отказ без обходных жестов/клавиш.
- `get_brightness`/`set_brightness` — условное публичное IOKit управление,
  диапазон 0–100, однозначный дисплей и проверка результата. На этом устройстве
  поддерживаемого дисплея не найдено; частные API и сторонние утилиты не добавлены.
- `mac_power(lock|sleep|shutdown)` — всегда отдельный код; фиксированные
  Control-Command-Q, `pmset sleepnow`, AppleScript System Events. Ответ сообщает
  отправку запроса, не обещает проверенное выключение/сон. Принудительных операций нет.
- `take_screenshot` — по явной просьбе PNG основного экрана, локальный путь,
  MIME, размеры и Agent ID. Destination выбирает код, каталог 0700, файл 0600.
  Изображение не анализируется и не передаётся во внешние сервисы.
- `find_files`/`open_path` — поиск имён и открытие в разрешённых местах;
  Finder открывает запрошенную папку, файл можно показать в Finder.

Окна используют непрозрачный одноразовый ID на 120 секунд с привязкой
к device/session. На исполнителе проверяются текущая просьба, PID/bundle,
title/identifier/frame/состояние; устаревшая, чужая или неоднозначная цель
отклоняется. Изменение геометрии ограничено видимой областью, move/resize требуют
свои пары параметров. После действия перечитывается результат; погрешность
геометрии до трёх пунктов учитывает округление macOS. Полный screen transform
не подменяется непроверенным хоткеем.

Живая проверка обнаружила, что AppKit ограничивает размер окна в старой позиции.
Исправлено: уменьшение до промежуточного размера, перенос, затем конечный размер
и read-back. После fullscreen добавлено ожидание завершения перехода AX/Space.

Файловые корни задаёт доверенная `MacConfig.file_roots`; по умолчанию
Documents/Desktop/Downloads. Клиент выбирает ключ корня, не произвольный каталог.
Запрещены выход через `..`/symlink, скрытые файлы, app-пакеты, скрипты и executable;
открываемые файлы ограничены форматами документов/изображений/медиа. Поиск не
читает содержимое, ограничен глубиной 8, 5000 элементами и 20 результатами;
неполнота явно помечается. Удаления/изменения пользовательских файлов нет.

В `set_volume` добавлена проверка реального уровня/mute после команды. Системные
ответы и результаты новых Mac-действий формирует `Tool.reply`: кратко, по факту,
без дополнительной генерации шутки моделью. Отправленный `open` описывается как
переданный macOS запрос, без неподтверждённого утверждения о готовности приложения.

Для прямой команды текст модели до исполнения удерживается. Если tool call
пропущен, генерация повторяется один раз; повторный пропуск даёт честный отказ.
Ложное «выполнил» не произносится и не сохраняется в проверенных регрессионных
сценариях. Это ограниченная защита прямых команд, не универсальный анализ
истинности всех фраз или полный NLU.

запуск, адресная активация, focus окна, левая/правая половина экрана, maximize,
resize, move, fullscreen и выход из fullscreen. Состояние подтверждалось AX
read-back. Приложение нормально закрылось, прежний фокус восстановлен.
Ни одно пользовательское приложение не завершалось ради теста.

**Сворачивание не прошло живую проверку.** AX принял действие, но minimized

## 5. Личность и реальные диалоги

Профиль сокращён, приоритет технической правильности поднят выше юмора.
В технических ответах разрешены блоки кода; запрещено выдумывать реализацию
класса/конструктор. Регрессия Java явно различает definite assignment локальной
переменной, default null поля и NPE при выполнении. Тяжёлая ссора не трактуется
как смерть человека. Реплика ожидания в серьёзных/технических темах — нейтральная
«Секунду». Русский голос, ударение «Чушпа́н» и wake-word сохранены.

Три реальные серии локальной Qwen: **29 отдельных запросов**, параметры модели
и конфигурация не менялись, загрузок других моделей нет. В первой серии
обнаружено ложное открытие без tool call; на этом основании добавлена защита кодом.
В итоговой серии открытие/батарея используют tools, запись памяти ждёт код,
Java правильно различает основные фазы ошибок, арифметика −2²/(-2)² верна,
тяжёлая ссора получает один конкретный вопрос, feedback не записывается фактом.

Осталось: «ты написал» вместо женского рода, непрошеные советы при усталости,
иногда слишком уверенный технический вывод без исходника, выдуманная человеческая
обстановка и лишнее ворчание. Стабильная естественность характера и отсутствие
фактических ошибок не гарантируются. Полная стилистическая приёмка не заявляется.
Все ответы, включая неудачные: [протокол этапа 3](CHUSHPAN_STAGE3_LLM_CHECK.md).
Протокол этапа 2 не перезаписывался.

## 9. Граница этапа 4 и оставшиеся риски

Для будущего зрения подготовлен только локальный screenshot contract. В этапе 4
предстоят явный доступ Screen Recording, безопасная загрузка/ограничение изображения,
выбор локального vision-модуля, адресность Agent, срок хранения/удаление снимков,
работа с недоверенным текстом экрана и запрет превращения его в разрешение действий.
Анализа экрана, OCR/vision API и автоматической внешней отправки здесь нет.

До безоговорочной приёмки Mac остаются сворачивание в текущей сессии,
живой цикл restore после успешного minimize, реальная музыка/аудио/снимок
при нужных разрешениях, а также стабильность речи Qwen. Это не повод начинать
этап 4 автоматически. Частные macOS API и обходы системных ограничений не добавлены.

Прочие границы: четыре цифры не аутентифицируют голос; локальный HUD всё ещё
без сетевой auth на loopback; Python/FS доверенные, не sandbox против локального
вредоносного процесса; закрытие приложения может прервать сессию; geometry может
частично измениться до отказа приложения. Общая память и профиль остаются
приватными данными, подтверждения не шифруют их. Эти ограничения сохранены
в архитектуре и дорожной карте.

Публичные механизмы: [NSRunningApplication](https://developer.apple.com/documentation/appkit/nsrunningapplication),
[AXUIElementSetAttributeValue](https://developer.apple.com/documentation/applicationservices/1460434-axuielementsetattributevalue),
[документированные клавиши macOS](https://support.apple.com/en-us/102650).

Работа этого прохода остановлена. Для перехода к этапу 4 требуется новое задание.
