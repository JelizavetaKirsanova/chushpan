# Поиск и открытие кино · Чушпан 0.2.8 (build 10)

Продолжение в Safari и интернет-поиск доработаны в
[версии 0.2.9](CINEMA_SAFARI.md); ниже сохранён отчёт предыдущего этапа.

Проверено 4 ноября 2026 года. Каталог TMDB, SQLite, HudBus и существующие
адаптеры воспроизведения сохранены. Нажатие «Смотреть» запускает оркестрацию
поиска; главная страница и обычная страница поиска не считаются результатом.

## 1. Что реализовано

- Стоимость источника: `FREE`, `PAID`, `MIXED`, `UNKNOWN`. Старые настройки
  мигрируют при чтении: free → FREE, subscription/rent/buy → PAID,
  unknown → UNKNOWN. Filmix и Kinogo автоматически бесплатными не назначаются.
- Фильтр бесплатного доступа допускает автоматический выбор только FREE
  (либо собственных локальных файлов). UNKNOWN остаётся отдельной видимой
  группой с явным ручным выбором. Это исключение действует только для выбранной
  конкретной страницы и не меняет стоимость источника на FREE.
- Отдельные настройки автоматического поиска, открытия, предпочтения сохранённого
  источника, бесплатного доступа, подтверждения платного сервиса, встроенного
  плеера и Safari. Для PAID/MIXED используется одноразовое подтверждение
  конкретного найденного результата с ограниченным сроком действия.
- TMDB дополнительно возвращает альтернативные названия и внешний IMDb ID.
  Поиск проверяет названия, год и Movie/TVSeries. Разные годы, трейлеры,
  главные страницы, рекомендации внутри списков и неподтверждённые совпадения
  не выбираются автоматически.
- Новый адаптер публичных карт сайта: опубликованные в robots.txt адреса XML,
  ограниченная глубина и размер, кеш, строгая проверка JSON-LD страницы.
  Слага URL используется только для отбора существующих адресов из карты;
  адреса фильма, поиска, сезона или серии не сочиняются.
- Соблюдаются robots.txt, дублирующиеся группы User-agent, запреты с wildcard,
  ограничения сервера и редиректы. Не используются учётные данные браузера,
  неофициальные устройства/API Filmix, CAPTCHA, DRM или обход авторизации.
  PublicHTTP сохраняет проверки публичного DNS/IP, TLS и каждого редиректа.
- При автоматическом поиске подключается официальный KION как альтернативный
  каталог. Его можно отключить в настройках источников. Стоимость сайта MIXED
  подтверждается [официальным каталогом](https://kion.ru/film), где присутствуют
  бесплатные фильмы и подписка. Стоимость отдельного найденного видео остаётся
  UNKNOWN, если публичные метаданные её не подтверждают; перед открытием KION
  по умолчанию всё равно требуется подтверждение платного сервиса.
- Сначала проверяется сохранённая конкретная ссылка. Если она доступна,
  полный поиск по сайтам не повторяется. Редирект сохранённой ссылки на другой
  адрес требует нового поиска. В SQLite сохраняются источник, ссылка,
  проверенные признаки, время проверки, область страницы, сезон/серия,
  позиция, длительность и история подтверждённого/ручного просмотра.
- Для сериала по умолчанию S1E1; дальнейший запуск восстанавливает выбранную
  серию. Проверенная общая страница сериала переиспользуется между сериями.
  Она открывается без попытки запустить произвольную серию: пользователь видит
  точные сохранённые сезон/серию и оставшееся действие на сайте.
- Встроенное прямое видео и доступный HTML5 через Safari используют реальные
  события плеера. Открытие страницы не считается началом просмотра. Для сайтов
  без доступа к плееру сохраняется ручная коррекция прогресса.
- Компактное окно поиска шириной до 560 px, этапы поиска/проверки/открытия,
  небольшие строки результатов и конкретные причины отказа. Выбор серии
  в карточке учитывается также верхней кнопкой «Найти и смотреть».

## 2. Что действительно проверено

С настоящими метаданными TMDB и публичными HTTP-запросами:

- `tv:250727`, «Бар „Один звонок“», 2025 →
  [страница сериала KION](https://kion.ru/serial/bar-odin-zvonok).
- `movie:157336`, «Интерстеллар», 2014 →
  [страница фильма KION](https://kion.ru/film/interstellar).
- `movie:27205`, «Начало», 2010 →
  [страница фильма KION](https://kion.ru/film/nachalo-2010).
- Все три адреса дополнительно открыты в чистом Chromium: HTTP 200,
  итоговый URL остался конкретной страницей, H1 соответствует названию.
  Вход, подписка и воспроизведение этих произведений не выполнялись.
- `tv:1396`, «Во все тяжкие», 2008: подтверждённого совпадения в карте KION нет;
  автоматическое открытие отменяется.
- Internet Archive: официальный advancedsearch + metadata действительно вернули
  проверенные страницы фильма Night of the Living Dead (1968), в том числе
  [этот результат](https://archive.org/details/Night.Of.The.Living.Dead_1080p).
  Это проверка страницы и метаданных; права конкретной копии, её стоимость
  и воспроизведение отдельно не подтверждались.
- Filmix, Kinogo, HDRezka: проверены реальные robots.txt и опубликованные карты;
  результат и ограничения перечислены ниже.

Автоматические проверки: 2257 Python-тестов, 109 frontend-тестов, Ruff,
форматирование Python и сборка TypeScript/Vite. Изолированный браузерный стенд
использует настоящий видеофайл без звука: запуск одним нажатием, подтверждение
движения времени, пауза, перемотка, следующая серия, сохранение, перезапуск SQLite,
компактное окно, UNKNOWN под бесплатным фильтром, ручной выбор и мобильная ширина.
Safari, микрофон и физические устройства в этих проверках не использовались.

Повторить read-only сетевую проверку:

```sh
.venv/bin/python -m scripts.check_cinema_sources --live
```

Опционально `--tmdb-directory` указывает локальную папку интеграции. Ключ
не печатается, не попадает в отчёт и не сохраняется в исходниках.

## 3. Какие сайты поддерживают автоматический поиск

- **KION:** поиск по опубликованным картам и проверка страницы. Три реальных
  положительных результата и один отрицательный перечислены выше.
- **Internet Archive:** официальный API для фильмов с проверкой названия,
  года, mediatype и признаков ограничения доступа; дополнены альтернативные
  названия. Общего поиска сериалов этот адаптер не обещает.
- **Другие совместимые сайты:** можно выбрать режим публичной карты сайта,
  если сайт публикует разрешённую карту и проверяемые Movie/TVSeries JSON-LD.
  Совместимость и доступность определяются по фактическому ответу.

## 4. Какие сайты поддерживают автоматический запуск

- Разрешённые прямые MP4/WebM/M4V со встроенным плеером и доступные HTML5-видео
  через Safari поддерживаются существующими адаптерами. Реальный запуск,
  позиция и управление проверены на изолированном видеофайле; это не доказательство
  работоспособности произвольного стороннего сайта.
- **KION:** автоматически открывается проверенная страница после подтверждения
  перехода (если оно включено). Программный запуск защищённого плеера и выбор
  серии не поддерживаются. Для сериала сообщаются сохранённые сезон и серия.
- **Internet Archive:** адаптер поиска открывает конкретную страницу.
  Автоматический старт произвольного найденного ролика этим адаптером не заявлен.
- **Filmix / Kinogo:** автоматический поиск и запуск на проверенных доменах
  не подтверждены; главная страница вместо результата не открывается.

## 5. Оставшиеся ограничения

- [Filmix robots.txt](https://filmix.gg/robots.txt) запрещает `/search` и `/play/`.
  Публичной карты в robots.txt нет; стандартная sitemap.xml ответила 404.
  Официальный разрешённый API не обнаружен. Неофициальные API с эмуляцией
  устройств/ключами PRO не подключались. Условия стоимости остаются UNKNOWN.
- [Kinogo robots.txt](https://kinogo.is/robots.txt) запрещает PHP/do=search и
  поисковые query-адреса. Опубликованная sitemap.xml вернула HTTP 403/Cloudflare.
  Защита не обходилась; условия стоимости остаются UNKNOWN.
- HDRezka публикует индекс карт, но проверка вернула 0 доступных адресов страниц.
  Запрещённые do=search/megasearch не использовались; совпадение не заявлено.
- Регион, подписка, авторизация, реклама и решение самого браузера об autoplay
  могут требовать действий на сайте. Поиск совпадения не доказывает права аккаунта
  на просмотр. Публичных разрешённых API управления плеерами KION/Filmix/Kinogo
  в этой реализации нет; DRM и чужие iframe не извлекаются.
- Первый поиск по большой карте ограничен 90 секундами на источник и может быть
  медленным. Индексы кешируются на час, результаты на пять минут, а сохранённая
  ссылка проверяется отдельно без повторного скачивания карты.
- Сезон/серия восстанавливаются в Чушпане. Автоматический выбор на внешнем сайте
  возможен только при наличии совместимого адаптера; общая страница сериала
  не выдаётся за подтверждённый запуск выбранной серии. Для неё прогресс ручной.
