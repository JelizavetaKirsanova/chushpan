# Статистика и свободный каталог кино

Страница «Статистика» использует существующий WebSocket `performance_query` и сохранённые
`request_traces`. Период общий для показателей, графиков, истории запросов, запусков сценариев
и собранной активности приложений. Сегодня/неделя/месяц/год — календарные интервалы до
текущего момента в настроенном часовом поясе; произвольные даты включают весь последний
день и ограничены 366 днями. Сравнение относится к предыдущему календарному интервалу
до того же времени суток. Новая схема хранения и миграция трасс не требуются.

## Семантика показателей

- Обращения: сохранённые запросы, кроме проверок активации микрофона.
- Средний отклик: `first_content_s` только завершённых, измеренных ответов. Для голоса
  это содержательный звук, для чата — текст. Полное время ответа показано отдельно.
- Выполненные команды и сценарии: результаты `success`/`completed` из командных трасс и
  реальных `scenario_runs`. Запрос сценария не считается второй выполненной командой.
- Успешные операции: доля подтверждённых успехов среди известных результатов. Ошибки и
  частичное выполнение остаются в знаменателе; отправленные, неподтверждённые, ожидающие
  и старые записи без результата показываются отдельно, без приписывания успеха.
- Кольцо считает запросы по основному типу операции. Это количество, а не время использования.
- STT/Tools/TTS используют объединение интервалов соответствующих этапов: параллельные
  промежутки не складываются дважды. LLM — время от начала модели до первого токена.
  Пропущенные измерения остаются `null`, линии не соединяются через пропуски.

«Производительность» сохраняет все прежние диагностические блоки в раскрываемых секциях.
Сортировка по полной задержке выбирает самые медленные запросы из всего периода, а не
только из последних 100. История сценариев, включая каждый шаг, находится в своей вкладке.
Вкладка приложений читает только ранее собранные события `analytics_events`, если таблица
существует. Она не включает сбор и не вызывает системные разрешения. JSON/CSV содержат
только выбранный период. Пустой обзор не создаёт пустые графики.

## Медиатека

Поиск, фильтры и AI-поиск находятся рядом с заголовком. AI-форма по умолчанию скрыта,
открывается в нормальном потоке страницы и закрывается после непустой отправки или Escape.
Она использует прежний обработчик чата; голосовая кнопка и голосовые команды независимы.
Вкладки не закреплены поверх постеров. Подборки и продолжение просмотра остаются в своих
разделах. Фильтры сохраняют существующие ограничения и поддерживают сортировку в drawer.
Постеры сохраняют ленивую загрузку, асинхронное декодирование, стабильные узлы и защиту от
устаревших результатов. Изменения статусов и прогресса используют прежнее хранилище.

## Проверка

```sh
npm --prefix frontend test
npm --prefix frontend run build
.venv/bin/python -m pytest -q
.venv/bin/ruff check backend/performance.py backend/statistics.py tests/test_statistics.py
.venv/bin/ruff format --check backend/performance.py backend/statistics.py tests/test_statistics.py
```

Повторяемая браузерная приёмка: `scripts/check_statistics_browser.py --database PATH
--playwright /absolute/path/to/playwright/index.mjs --chromium /absolute/path/to/chromium`.
Стенд делает SQLite backup в временную директорию, использует реальный HUD/WebSocket и
реальные сохранённые измерения. Поиск каталога в стенде работает по кешированным метаданным
медиатеки, без внешних API и ключей. Избранное меняется только во временной копии.
Проверяются семь вкладок, диагностика, пустой период, поиск, drawer, AI-форма, Escape,
стабильный hover, прокрутка и ширины 1440/900/600/390. Изображения — в `/tmp`.
Демонстрационные данные в рабочий интерфейс не добавляются. Проверка не запускает
микрофон, воспроизведение или физические устройства.
