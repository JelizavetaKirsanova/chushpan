# Источники кино: аудит и проверенный прототип

Дата: **5 ноября 2026**, Europe/Tallinn. Проверялась текущая `main` и отдельные
временные процессы, без обновления установленного `/Applications/Чушпан.app`.
Исходная архитектура, остальные разделы и личные настройки сохранены.

## Результат

**Полный Sintel действительно воспроизведён внутри основного интерфейса Чушпана
в настоящем WKWebView.** Это открытый короткометражный фильм целиком, около
14 минут 48 секунд, а не трейлер; проверка не означает поддержку произвольного
полнометражного каталога. Отдельно успешно проверен настоящий AVKit.

В WKWebView также воспроизведён **Caminandes, сезон 1, серия 2**, 146,05 секунды.
Проверены пауза, перемотка, fullscreen окна macOS, SQLite и восстановление после
пересоздания сервиса. Смена профиля источника проверялась на двух конфигурациях
одного Internet Archive. Положительные прогоны Caminandes и финальный
изолированный Sintel прошли; один промежуточный повтор Sintel выявил зависание
автоматического запуска после переключения. Переключение между
независимыми провайдерами этим испытанием не подтверждается.

Lampac, Filmix, KinoBox и pleer.video не включены в автоматический просмотр:
живое воспроизведение полного произведения через них не подтверждено.

## Причины ошибок в Чушпане

Аудит начат с локального кода. PlaybackManager, SourceResolver, AVKit, WebKit,
отдельный трейлер и проверка соответствия полного видео **уже существовали**.
Они расширены без переписывания кинотеатра.

| Участок кода | Что происходило | Исправление или ограничение |
|---|---|---|
| `backend/cinema/service.py`, `Cinema._open`, выбор `embed` | ArchiveAdapter возвращал правильный `media_url`, но WebKit получал исходный `target.link.url`. Сохранённая `/details/Sintel` или `/embed/Sintel` оставалась HTML-страницей вместо MP4 | В плеер передаётся разрешённый `resolved.media_url`; совместимость AVKit тоже определяется по этому адресу. Регрессии отдельно проверяют оба движка |
| `service.py`, `source_result`, поиск сохранённой ссылки | После разрешения страницы в MP4 результат сохранял link_id, но поиск привязки требовал совпадения старого URL страницы с новым URL MP4. Живой resume завершался `RuntimeError: coroutine raised StopIteration` | Существующая привязка выбирается по source_id/link_id; при исчезновении возвращается понятная ошибка, исходная пользовательская ссылка сохраняется |
| `backend/cinema/models.py`, `Preferences.open_in_safari`; `service.py`, `_open` | Значение по умолчанию `True` блокировало встроенный плеер даже при разрешённом прямом видео | Для новых настроек `False`; уже сохранённый выбор пользователя не переписывается. Переключатель объясняет приоритет Safari |
| `service.py`, `_open`, ветка `native` | В desktop-режиме прямое видео автоматически уходило в отдельное окно AVKit | Разрешённое сетевое видео по умолчанию остаётся в основном WebKit-интерфейсе; AVKit доступен явно, локальные файлы сохраняют нативный путь |
| `service.py`, `_open`, `player='embedded'` | При невозможности встраивания явный запрос мог дойти до Safari | Теперь возвращается `unsupported_source`, страница не открывается молча |
| `backend/cinema/native_player.py`, `AVPlayerAdapter.open` | AVKit проверял готовность и движение времени, но не сравнивал длительность с доказательством провайдера | Сравнение до play/seek; короткое превью даёт `duration_mismatch` |
| `backend/cinema/playback.py`, `SourceValidator.player` | Проверка прямого файла могла опираться на URL и необязательный runtime каталога, не используя точную длительность провайдера | Проверяется длительность конкретного проверенного файла; несовпадение снимает `content_verified` |
| `frontend/src/cinema_player.ts`; `service.py`, `embedded_event` | WebKit запускал MP4 без сравнения длительности с известным полным произведением | Проверка метаданных до autoplay и независимая проверка события backend; при отказе прогресс не записывается |
| `backend/cinema/sources.py`, `SourceManager._search` | Новый непроверенный источник мог автоматически выбираться по метаданным | Новый источник требует первого явного выбора или подтверждённого плеера. HTTP 200 не даёт право автовыбора. Сохранённые пользователем ссылки и предложения с обязательным подтверждением сохраняют прежний маршрут |
| `backend/cinema/diagnostics.py`, `check/publish` | Новый запуск проверки заменял предыдущую ошибку | Хранятся последние 20 ошибок источника и время полной успешной проверки. Старый отчёт после изменения конфигурации не показывается как актуальная работоспособность |
| `backend/cinema/store.py`, `save_source` | Смена способа просмотра могла сохранять счётчик прежних успешных запусков | Изменение адреса/адаптера/режима поиска/встраивания требует новой проверки; переименование и порядок не стирают успешные запуски |

### Цепочка от каталога до видео

1. **Каталог и поиск произведения:** `backend/cinema/tmdb.py`, `TMDB.search`,
   `detail`; `catalogue.py`. TMDB даёт метаданные и внешние ID, не право просмотра
   и не URL полного фильма. `official_trailer` вызывается только явным действием
   «Трейлер» (`service.py`, `trailer`; `commands.py`).
2. **Поиск источника:** `sources.py`, `SourceManager.search/_search`,
   `internet.py`, `PageVerifier`; пользовательские настройки и стоимость доступа
   сохраняются. Sitemap или поисковая выдача сами по себе не подтверждают видео.
3. **Совпадение:** `classification.py`, `same_work/classify` проверяют тип,
   название/внешнюю идентичность, известный год и для сериала сезон/серию.
   Связь `associatedMedia/encoding` проверяется относительно активного медиа.
   Промо, несколько плееров, чужой iframe и неизвестный тип не становятся полным
   просмотром. Неполные метаданные могут дать ручной вариант с объяснением.
4. **Разрешение:** `archive_open.py` связывает произведение, автора, год,
   лицензию и точное имя оригинального MP4 либо разрешённой производной.
   Длительность из живого API сравнивается с небольшим каталогом известных работ.
5. **Плеер:** `service.py`, `_open`; `native_player.py` и `avplayer.swift` для
   AVKit; `frontend/src/cinema_player.ts` для `<video>` внутри WKWebView.
   Нельзя считать iframe URL совместимым AVKit-потоком.
6. **Подтверждение:** `PlaybackManager.confirmed/observe` и `embedded_event`
   переводят сессию в PLAYING после движения времени. Ответ подготовки остаётся
   `playback_confirmed=false`, `WAITING_FOR_PLAYER`.
7. **Прогресс:** `service.py`, `save`; `store.py`, `progress`,
   `cinema_playback_state`. Нулевые, нечисловые, ошибочные и незавершённые seek
   не заменяют корректную позицию. Сессия и команда имеют отдельные токены.
8. **Голос:** `commands.py` и `Cinema.execute` используют ту же сессию; в живом
   WKWebView испытании текстовые команды паузы и перемотки прошли без записи
   микрофона. Само распознавание речи не испытывалось.

## Универсальный контракт и выбор подхода

Сохранены существующие `SourceAdapter` (`sources.py`) и `PlayerAdapter`
(`adapters.py`): поиск/resolve/серии отделены от открытия и наблюдения плеера.
Реестр принимает только доверенный код приложения, а не скрипты из настроек.

`capabilities()` теперь описывает имя, поиск, movie/series, форматы, сезоны/серии,
озвучки, способы воспроизведения, управление и статус проверки. Это **заявленные
возможности** (`capabilities_verified=false`), проверяемые конкретным плеером.
Например, наличие MP4 не гарантирует поддержку кодека каждым движком.
`ArchiveAdapter.getEpisodes` возвращает три известные работы Caminandes;
чужим сериалам не генерируются выдуманные URL или номера эпизодов.

Используются статусы `working`, `partial`, `requires_authorization`, `unavailable`,
`not_verified`, с русскими подписями. HTTP 401 явно требует авторизации;
HTTP 403/429 не объявляются автоматически запросом логина. Полная диагностика
считает «Работает» только после всех этапов; подтверждённый обычный просмотр
может отдельно свидетельствовать об успешном запуске источника. Старые успехи
не гарантируют будущую доступность и не доказывают весь каталог.

Автовыбор нового источника разрешён после реального успешного просмотра или
полной диагностики. Первое точное совпадение пользователь выбирает явно.
Сохранённая ссылка — уже сделанный пользователем выбор; новый домен с обязательным
подтверждением может быть предложен, но не открывается без этого подтверждения.
`preferred` сам по себе не превращает непроверенный новый источник в основной.

Из Lampac полезны разделение provider registry, ID mapping, выбор по приоритету и
короткий кэш неудач; из go-filmix — явные типы сезона/серии/озвучки и проверка
качества/превью; из KinoBox — отделение оболочки от конкретного плеера. Это
архитектурные идеи, сторонний исполняемый код не добавлен.

**Рекомендуемый путь:** официальный разрешённый API → точная идентичность
произведения/серии → проверенный MP4/HLS → собственный `<video>` в WKWebView.
AVKit — отдельный явно выбираемый движок для совместимых файлов. Внешний
iframe без согласованного протокола управления остаётся частично поддерживаемым.
Новый сервер ради первого прототипа не требуется.

## Интерфейс источников

Существующий путь: **Настройки медиатеки → Источники просмотра**. Сохранены
фиолетовые CSS, включение/выключение, порядок drag-and-drop и кнопками,
предпочтение, добавление и настройка источника.

Добавлены понятные статусы и возможности, форматы, история ошибок в отдельном
раскрывающемся блоке, время полной успешной проверки. Подпись «Сайт отвечал»
отделяет успешное HTTP-соединение от успешного просмотра. Общая кнопка называется
**«Проверить все источники»**. Подробная матрица и явные испытания Safari/AVKit
находятся под «Подробные проверки и запуск видео». Автоматическая проверка сайтов
не запускает видео и не меняет прогресс.

## Реальные испытания и границы доказательств

Проверки используют публичное внешнее видео, настоящий системный плеер и
производственный Cinema/SQLite. Локальное тестовое видео, HTTP-моки и заглушки
медиаплеера в этих испытаниях **не использовались**. Временный HTTP-сервер —
обычный HUD данного тестового процесса; он завершается вместе с тестом.

| Проверка | Фактическое наблюдение |
|---|---|
| WKWebView, полный Sintel | Оригинальное и русское названия разрешены в один MP4; API duration 888,06 с; currentTime 0,234 → 1,403 с, PLAYING подтверждён интерфейсом и backend |
| Пауза и перемотка WKWebView | `Cinema.execute` с текстовыми командами: paused=true; seek примерно +10 с завершён, позиция записана в SQLite |
| Fullscreen WKWebView | Нажата кнопка производственного плеера; подтверждён настоящий `NSWindowStyleMaskFullScreen`, а не только CSS-класс |
| Возобновление WKWebView | Cinema закрыт и пересоздан на той же временной SQLite; с 11,403 с восстановлено около 8,656 с с настроенным отступом 3 с |
| Конкретная серия | Caminandes S01E02 → `Caminandes2GranDillama/02_gran_dillama_1080p.mp4`, API duration 146,05 с; currentTime 0,208 → 1,418 с; пауза/seek/fullscreen/SQLite/reopen прошли |
| Смена источника | Caminandes: два профиля Internet Archive, новая сессия/токен и запуск подтверждены. Промежуточный повтор Sintel: ready=4, duration=888,02, seeking=false, paused=true, WAITING_FOR_PLAYER — автоматический запуск не подтверждён. Финальный изолированный повтор Sintel полностью прошёл, включая сохранённую embed-страницу второго профиля. Независимый второй провайдер не проверен |
| AVKit из актуальных исходников | Прямой MP4: duration 888,02 с; currentTime 27,133 → 28,334 с; pause, seek 40 с, fullscreen и восстановление около 37,195 с прошли. Сохранённая embed-страница после исправления тоже запускает полный MP4, но повторное открытие в двух поздних прогонах вернуло seek_interrupted; эти прогоны завершились exit 1 |
| Ошибки реальных сервисов | pleer.video — HTTP 523; KinoBox API — RemoteProtocolError. Это ошибки проверки, не успешная интеграция |
| Подмена превью, чужая серия, изменившийся URL, отказ разрешений | Отдельные регрессионные тесты с явно обозначенными doubles; не выдаются за испытания работающего внешнего агрегатора |

Проверенная длительность соответствует **полному файлу** и открытой лицензии.
Не выполнялся просмотр каждой секунды до финальных титров; доказательства —
идентичность оригинала/производной, метаданные полного файла, длительность
системного декодера и фактическое воспроизведение с управлением.

Повторяемость пока ограничена: один ранний повтор WKWebView не подтвердил
старт за 60 секунд, следующий прошёл основной просмотр и пересоздание SQLite,
но остановился на смене профиля. AVKit отдельно выявил `seek_interrupted`.
Эти неудачные прогоны не заменялись локальным видео или моками. Финальный изолированный
WKWebView-прогон без запроса дополнительного KION прошёл целиком, включая поиск
через SourceResolver и первый явный выбор источника. Причина промежуточного отказа
автозапуска после переключения не установлена; факт загрузки не выдан за PLAYING.
Полная стабильная интеграция всех повторов и движков пока не заявляется.

Результаты запусков сохранялись только во временные JSON вне репозитория.
Команды для повторения из корня проекта:

```sh
npm --prefix frontend run build
.venv/bin/python -m scripts.check_cinema_webkit --live --title Sintel
.venv/bin/python -m scripts.check_cinema_webkit --live --title Caminandes2
.venv/bin/python -m scripts.check_cinema_external --live --engine native --title Sintel
```

WKWebView-скрипт проходит живые SourceResolver/поиск/первый явный выбор,
производственный HUD, голосовые текстовые команды, сохранение/пересоздание
SQLite и переключение на сохранённую страницу второго профиля. AVKit-скрипт
собирает помощник из текущего Swift-кода, не подбирает старый бинарник из `dist`;
сохранённая embed-страница должна разрешиться в MP4. Exit 0 требует полного
набора обязательных проверок, одного движения currentTime недостаточно.

## Что осталось

- Подтвердить права и контракт каждого нового коммерческого провайдера отдельно;
  доступность репозитория и лицензия его кода не заменяют это.
- Lampac: согласовать необходимость собственного сервера, выбрать правомерные
  провайдеры и разобраться с расхождением лицензий до возможного переноса кода.
- KinoBox: получить разрешение/поддерживаемый API и документированный протокол
  событий iframe. Не ослаблять same-origin/DRM/macOS ради управления.
- Расширять каталог открытых работ только после проверки автора, лицензии,
  идентичности файла и фактического плеера; произвольная запись Archive не
  считается лицензированным полным фильмом.
- Проверить независимые источники, несколько реальных озвучек и больший набор
  кодеков/регионов. У текущих открытых работ нет набора русских озвучек для такого
  испытания. HLS/DRM/AirPlay и реальные коммерческие серии этим прототипом не
  подтверждены; настройки безопасности и физические устройства не менялись.
- Обновление установленной версии приложения остаётся отдельным этапом.
