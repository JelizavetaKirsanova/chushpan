# Медиаплеер, приложение YouTube Music, разрешения и каталог

Исправляющая сборка: **0.3.1 (14)**. Архитектура, личная SQLite, настройки,
история просмотра и существующие музыкальные команды сохранены. Установка новой
копии отдельно от сборки; этот выпуск создаётся в `dist/Чушпан.app`.

## Поведение

- HTML5-адаптер выбирает сохранённую страницу Safari, ждёт динамический плеер,
  восстанавливает позицию и отдельно проверяет движение времени и fullscreen.
  Обычные источники HTML также получают попытку HTML5-управления. Страница всего
  сериала остаётся ручной: автоматически угадывать серию нельзя.
- Поддерживаются доступные iframe того же origin. Неоднозначный, защищённый или
  междоменный плеер получает понятное ограничение. При отказе autoplay/fullscreen
  предлагается настоящая кнопка на странице: пользовательский клик вызывает
  `play()` и Fullscreen API. Синтетические жесты и обход защиты не используются.
- Сохранённая серия и ссылка с озвучкой сохраняются. Если плеер предоставляет
  HTML5 AudioTrack API и точное имя/язык, дорожка выбирается и проверяется. Для
  внутренних переключателей сайта без такого API подтверждения озвучки нет:
  выводится просьба проверить её вручную. Прогресс при ошибке не обнуляется.
- Журнал этапов включает `OPEN_SAFARI`, `DETECT_PLAYER`, `RESTORE_POSITION`,
  `PLAY`, `FULLSCREEN`, `SAVE_PROGRESS`; успех одного этапа не означает успех всех.
- YouTube Music автоматически определяется по `.app`, bundle ID и манифесту
  Safari Web App / PWA. Произвольное нативное приложение выбирается явно через
  системный диалог. Выбор сохраняется в личных настройках SQLite и применяется
  к существующему музыкальному сервису без перезапуска.
- Запуск/повторное открытие использует NSWorkspace / Launch Services и проверяет
  frontmost bundle ID. Для экрана входа macOS возвращается просьба разблокировать
  Mac. Новая вкладка Safari при запуске приложения не создаётся. Переходы плейлистов
  используют ссылки внутри выбранного приложения. Если нужной ссылки нет,
  требуется открыть её в библиотеке/поиске приложения; внешняя URL-навигация,
  способная перенаправить Safari Web App в Safari, отключена.
- В Настройках → Интеграции доступны найденное приложение, автоматическое
  обнаружение, ручной выбор, проверка запуска и разрешение браузерного fallback.
  При автоматическом режиме браузер используется только с разрешённым fallback
  и при отсутствии приложения. Явный старый `transport: safari` остаётся доступен
  как расширенная конфигурация только при `allow_browser: true`.
- Существующий PermissionCenter автоматически читает статусы при запуске;
  реальные системные запросы остаются явными действиями пользователя. Окно
  подготовки объясняет микрофон для голосового режима и разрешает продолжить
  текстом. Отказ/закрытие запоминаются для того же набора отсутствующих прав.
  Возврат в приложение повторяет проверку. Необязательные права не блокируют чат.
  Apple Speech и напоминания честно помечаются неиспользуемыми, права LAN/файлов
  без надёжного preflight остаются непроверенными. Уведомления читаются через
  UNUserNotificationCenter; запрос возможен по кнопке в подписанной копии.
- Жанры TMDB разрешаются отдельно для movie и TV, включая совместимые старые
  названия категорий. OR передаётся через `|`, AND через `,`. Для фильтрованных
  трендов и неперсонализированных подборок используется Discover. Недоступный
  для типа жанр объясняется, фильтры не сбрасываются.
- Если локальные правила исключили всю страницу, каталог проверяет до пяти
  страниц за запрос, возвращает следующий непросмотренный номер и продолжает
  пагинацию. Русские буквы в названии, исключение аниме/анимации и личной истории
  продолжают действовать. Общий счётчик TMDB не выдаётся за точное число после
  локальных фильтров. Сброс фильтров требует подтверждения. Сеть/API дают ошибку
  и повтор, а не ложное «ничего не найдено».

## Ограничения и действия пользователя

Fullscreen/autoplay могут требовать клика по кнопке на странице или настройки
автовоспроизведения Safari. Междоменные/DRM/внутренние плееры без доступного API
остаются ручными. Необходимые права выдаются исполнителю, указанному в центре
разрешений. Для повторного живого запуска приложения нужно разблокировать Mac.
Настоящие внешние сайты, внутренние переключатели озвучки и воспроизведение
личного плейлиста не объявляются проверенными по локальным фикстурам.
